## What the check found

`summarize` now reports `contact_required: None` for an episode that is not
cleared (IMP-10), but `m3_accuracy` still does `bool(contact_required)`: an
**undecided** episode is silently counted as "no hidden contact". That is the
same fabrication class as the oracle-truth defect, one layer up: the reporting
layer stopped lying, the scorer did not.

## F1 — the M3 scorer must refuse undecided episodes

Change `m3_accuracy` to return `{"accuracy", "scored", "excluded"}` and exclude
any episode whose `summarize(...)["cleared"]` is False, and any episode whose
contact field is `None` for another reason. Callers and tests update; the
shipped-corpora numbers must be unchanged (they are all cleared), and the
excluded count must be 0 there — asserted, so a future corpus that silently
loses episodes shows up as a number, not as a nicer score.

Gate: new test constructs an uncleared episode and asserts it is **excluded**,
not wrong; mutation: reverting to `bool()` makes the test RED.

## F3 — A3 degradation curve (evidence for the operator's decision, not a claim)

A2 showed a deterministic residual scores 1.00 when the boundary position is
exact. The open question for any learned arm is how fast that dies when the
observation is coarsened. Measure, do not register:

- quantize the logged boundary position to `q` units for `q ∈ {0.01, 2, 5, 10, 20}`
  and report top-1 on `parallel_recrossing_corpus(6)`;
- report where top-1 crosses the 0.25 chance floor.

This is instrument evidence for choosing a harder task; registering it as a
claim needs the operator. Gate: `scripts/a3-degradation.py` prints the curve and
exits 0; numbers copied into this file's status section, not into the prereg.

- **F3 DONE, and the plan's own prediction was WRONG.** It expected the signal
  to die around a 10-unit grid. Measured on `parallel_recrossing_corpus(6)`
  (chance 0.25):

  | q (units) | grid top-1 | jitter top-1 |
  |---|---|---|
  | 0.01 | 1.00 | 1.00 |
  | 2 | 1.00 | 1.00 |
  | 5 | 1.00 | 0.50 |
  | 8 | 1.00 | 0.50 |
  | 10 | 1.00 | 0.50 |
  | 20 | 1.00 | 0.33 |

  Grid rounding never degrades: quantizing y=45 and y=53 to a 20-unit grid
  gives 40 and 60, preserving (even widening) the ordering that carries
  identity, and it snaps the velocities to 0. Jitter is the degradation that
  removes information: 0.50 at 5 units, 0.33 at 20, still above the 0.25 floor.
  Consequence for A3: a task that actually needs a model must coarsen *with
  noise*, not with a grid, and roughly in the 5-20 unit band; the chance floor
  for that variant must be measured before any claim is registered.
