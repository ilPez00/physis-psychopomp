## The three controls, and what each must show

1. **Feedback removal.** Run the `feedback` arm with its corrective transfer
   suppressed from tick 1 — i.e. the organisation cannot act on imbalance. It must
   then behave like `open-loop`: residence 0 at `p = 2`. If a "feedback" arm that
   cannot feed back still recovers, the measured difference was never feedback.
2. **Sham.** Perturb with the *sign flipped* (`p = -2`): both roles displaced, no
   net imbalance. Residence must be **3** in both arms — the discriminating cell
   needs an imbalance, not merely a disturbance. This is the control that says the
   effect is about balance rather than about change.
3. **Independent copy.** Run two `feedback` arms from **independent** initial
   inventories (different component counts) and require that their recoveries are
   *not* equal — i.e. the result depends on the organisation's own state, not on a
   shared constant. Where the two happen to coincide, that must be reported as a
   tie rather than counted as agreement.

### P2 failed because my control was a no-op, and the code says why

I expressed "feedback removal" by passing an identity `nominal` to the **feedback**
arm. `run()` reads `nominal` only on the `open-loop` branch:

```python
if arm == "feedback":
    moved = _feedback(loads)
else:
    replay = nominal.get(tick) if nominal else None
```

So the arm I called `feedback-removed` ran the ordinary feedback path and
recovered normally (residence 3). The failure is real and correctly attributed:
**`turnover.py` has no way to suppress feedback**, and a control that needs a knob
the fixture lacks is exactly the case this card said it would report rather than
fake. Feedback removal is **not constructible** with the current signature.

### P4 failed, and the reason is a fixture property worth knowing

Both targets reach the same absolute state `(5, 5)` by tick 4, so their transfer
sets are identical and the "state-dependence" reading is false **for this
fixture**: the recovery target is a constant, not a function of the initial
inventory. R-P1.49's claim is about totality of turnover and structural recovery,
not about distinct recovered states — but C2 asked for an independent-copy control
and this is the answer: **with a fixed initial inventory there is no independent
copy to have**, and the recovered state does not vary with the role that moved.
