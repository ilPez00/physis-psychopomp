# Preregistration — R-P1.55: a laned but false proposal (2026-11-23)

Claim `89d36cf5-3607-44f3-a0d5-a984add95c54`. Prior: **0.7**. Freeze on origin
before running. Status at freeze: **not measured**.

R-P1.54 measured the easy refusal: an unlaned predicate is rejected and nothing is
planted. This card asks the question that one could not — **what happens when the
predicate is type-legal and the edge is false?** A decoder that can plant a wrong
belief is a different risk from one that cannot write at all.

## Setup

Fresh scratch world (`/tmp/opencode/laned-*`): two text files, `physis observe`.
Observation produces `file:src/a.txt`, `file:src/b.txt` and one
`document:src/<name>.txt::1` per file, with a true `DEFINES` edge from each file to
its own document — the lane `file → document` therefore exists.

Candidate: `F = file:src/b.txt --DEFINES--> document:src/a.txt::1`. Type-legal
(file defines a document), and **false**: `b.txt` contains `beta`, not `alpha`.

## Predictions (fixed now)

- **Z1 — capacity.** Both endpoints exist as entities; the true edges
  `a→a-doc` and `b→b-doc` are present; `F` is absent; `file:src/b.txt` has exactly
  **1** incident relation before the run.
- **Z2 — admission does not check truth.** `declare F` returns **0** and the log
  grows by **1**. If it instead returns 1, this card's premise is wrong and that is
  the finding.
- **Z3 — the fold then believes it.** `claim F` returns **0 VERIFIED** after the
  declaration, having returned 2 before it.
- **Z4 — it is visible in the graph.** `object get file:src/b.txt` shows **2**
  incident relations afterwards.
- **Z5 — nothing was displaced.** `claim file:src/b.txt DEFINES
  document:src/b.txt::1` still returns **0**; a second edge was added, the true one
  was not replaced.
- **Z6 — the decoder still claims nothing.** The plan that produced `F` stays
  `HYPOTHESIZED` with `verifier.status = NOT_EVALUATED`. The failure, if any, is
  the writer's admission boundary, not a decoder promotion.

`ontology-check` before and after is **reported, not predicted**: it may or may not
flag the fabricated edge, and guessing its verdict would be a prediction about a
tool I have not measured.

## Rules

If `declare F` returns anything but `0`, Z2–Z5 are falsified as written and the
card records the refusal as the finding — that would mean the fold does constrain
this lane, which is better news than the prediction. No predicate or endpoint is
swapped to rescue a prediction.

## Limits

- One ontology version (`physis` 1.9.1), one lane, one false edge. This says
  nothing about lanes with cardinality constraints or mandatory provenance fields.
- The world is a throwaway; a project store would need an authorisation step,
  which this card does not test and which the plan has not built.
- A `0` here does **not** mean Physis is wrong to admit: an observation is
  evidence of what was asserted, and the writer accepts an assertion. It means a
  decoder needs its own authorisation gate before it may assert.
