# PREREG — R-P1.41 the formula, in the regime where it has content (2026-11-22)

Status: **registered before the run**; claim registered in the store before the
run. Roadmap `docs/ROADMAP.md` R-P1.41.

R-P1.40 tested `1 − (1−p)^N` and "passed" **vacuously**: with `N = 56`
opportunities, the formula predicts ≈ 1.000 for every `p ≥ 0.2`, so R1/R2/R3 were
true for the wrong reason, and R4 was empty because my "short window" geometry
produced the same `N = 56`. Three of its four predictions were unfalsifiable as
built. This card puts the test where the formula actually discriminates: **small
N**.

## Design

Same world, same comparison (a relabelled pair differs iff ≥ 1 marker fired), but
`N` is controlled by shortening the episode, and `p` is swept where the prediction
is far from both 0 and 1:

| cell | `steps` | opportunities `N` |
|---|---|---|
| A | 5 | **1** |
| B | 15 | **2** |
| C | 25 | **3** |

`p ∈ {1.0, 0.6, 0.3, 0.0}`, **400 realizations** per cell (binomial SE ≤ 0.025 at
`p = 0.5`, so a ±0.06 band is a real test). Bodies stay visible for the whole
window, so `N` is exactly the count of marker slots.

Predictions become sharp: `N = 1` gives `p` itself; `N = 3, p = 0.3` gives
`1 − 0.7³ = 0.657`; `N = 2, p = 0.6` gives `0.840`.

## Predictions (fixed now)

- **S1 (small-N formula).** For every cell, measured resolvable fraction is within
  **±0.06** of `1 − (1−p)^N` with `N` measured from the same episode at `p = 1`.
- **S2 (the linear case is exact).** At `N = 1` the fraction equals `p` within
  ±0.05 at every `p` except `p = 0` where it is exactly 0 — this is the sharpest
  possible check and it does not depend on any exponent.
- **S3 (the cells really differ).** The three geometries produce **distinct** `N`
  (1, 2, 3), so the card cannot repeat R-P1.40's mistake. *Falsified if any two
  agree* — which would make the whole design vacuous again.
- **S4 (reliability is per-opportunity, not per-episode).** At fixed `p`, going from
  `N = 1` to `N = 3` raises the fraction by at least `(1−p) − (1−p)³ − 0.06`, i.e.
  the effect of *more chances* is visible and matches the algebra.

### What this completes

Identity identifiability is now a formula, not a slogan:

- **coverage** sets `N` (a body seen for fewer slots has fewer chances — R-P1.39's
  hidden case is `N = 0`, hence 0 at every `p`);
- **reliability** sets `p`;
- and the two compose in the exponent, measured at small `N` where the arithmetic
  actually discriminates.
