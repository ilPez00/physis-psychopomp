## Predictions (fixed now)

- **P1 — lossless.** One record per *observable* event: count equal, `props`
  equal to the event attrs, `at = event_step * dt` seconds.
- **P2 — no hidden state.** The oracle log is never read; a counterfactual
  export is refused (`sim:*` provenance only); subjects stay identity-free.
- **P3 — deterministic.** Same episode ⇒ identical JSONL bytes; read-back
  round-trips.
- **P4 — live connector NOT MEASURED.** The concrete Physis ingest schema has
  not been read from a physis-next branch checkout in this session; a claim of
  compatibility would be fabrication. The contract here is the producer format
  plus the seam.

If P1 is not lossless, the export is not a view of the log and A4 cannot cite
it; if P2 fails, the export is a leak.
