# Preregistration — R-P1.52: decoder contract, with capacity gates and a
deterministic baseline (2026-11-23)

Claim `bb592f87-84fa-4142-aefc-f6adbe83a296`. Prior: **0.85**. Freeze on origin
before running. Status at freeze: **not measured**.

Follow-up to [R-P1.51](2026-11-23-PREREG-R-P1.51-decoder-contract.md), whose D4
failed because its `noisy` arm omitted both missing edges, making the predicted
agreement impossible. The correction here is not the prediction — it is **an
assertion that each arm has the structure its prediction relies on**, checked
before any score is computed.

## Fixed graph

As R-P1.51: entities `n1…n6`, predicate `X` plus one `Y`;

```
T = { (n1,X,n2), (n2,X,n3), (n3,X,n4), (n4,X,n5), (n5,X,n6), (n1,Y,n6) }
snapshot = T − { (n2,X,n3), (n5,X,n6) }          # 4 observed, 2 missing
F = (n2,X,n4)                                     # one fabricated edge
shuffled = T with targets permuted n1→n4, n2→n5, n3→n6, n4→n1, n5→n2, n6→n3
```

## Capacity gates (must pass before scoring)

- **C1** every arm's edge set is a subset of the entity set, and the snapshot has
  exactly 4 edges and 2 missing true edges;
- **C2** the `agreed` arm has **exactly 2** edges present in both worlds and absent
  from the snapshot, and **exactly 1** disputed edge;
- **C3** the `shuffled` world shares **0** edges with `T`;
- **C4** closure-only proposals are computed from observed edges alone and share
  **0** edges with the set of missing true edges.

If any capacity gate fails, the card records the failure and scores nothing.

## Arms and predictions (fixed now)

| arm | proposals come from | predicted precision | predicted recall |
|---|---|---|---|
| **no-repair** | nothing | undefined (0 proposals) | **0.0** |
| **closure** | transitive closure of observed `X` edges | **0.0** | **0.0** |
| **exact** | admissible world = `T` | **1.0** | **1.0** |
| **shuffled** | the permuted world | **≤ 0.5** | 0.0 |
| **agreed** | worlds = `{T, T ∪ {F}}` | **1.0** on the two agreed edges | **1.0** |

- **D1** no-repair proposes nothing; recall 0.0 by definition, and the card says so
  rather than reporting precision.
- **D2** closure proposes at least one edge (capacity C4) and recovers **none** of
  the missing true edges: precision and recall **0.0**. This is the arm a
  purely structural rule cannot reach, and it is the reason the benchmark exists.
- **D3** exact: precision **1.0**, recall **1.0**, all proposals `HYPOTHESIZED`.
- **D4** shuffled: precision **≤ 0.5**, `false ≥ true`.
- **D5** agreed arm: the two missing true edges are marked
  `all_surviving_worlds`, `F` is marked `disputed`, and **exactly one**
  `REQUEST_EVIDENCE` is emitted, naming the positive-gain probe.
- **D6** no operation is applied in any arm: `verifier.status` is
  `NOT_EVALUATED`, `base_revision` equals the snapshot's, and the only statuses
  emitted are `HYPOTHESIZED` and `unknown`. Order-shuffled decodes serialise
  identically.

## Limits

- One hand-built graph; the closure baseline is *one* deterministic rule, not the
  class of them. A different rule might recover a missing edge, and this card
  would not notice.
- The decoder still cannot retract, so a false edge already in the snapshot is out
  of scope.
- Contract only: not repair precision of a predictor, not admission by Physis.
