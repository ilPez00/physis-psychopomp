# Preregistration — R-P1.71: a mask with a hole, and the event inside it

Claim `2b0c9ed6-3458-4e3d-9a14-c0139f6ff330`, registered at **prior 0.5** before the run. Freeze on origin before
any measurement. Status at freeze: **not measured**.

R-P1.70 set out to test a reflex mask and, after the run, found it had never made
one: `sim.py`'s occluders are a **union**, so `poly_o` only ever adds mask, and an
L polygon on top of the default rectangle is a solid rectangle with extra corners.
Its own correction records that, with the one-line proof.

This card runs the fixture that correction names, and asks the question P3 of
R-P1.70 was supposed to answer.

## The fixture, verified before the card was written

```
cfg = SimConfig(o=(2, 4, 2, 4), poly_o=(L,))     # first rect parked in a corner
observable(cfg, 46, 45) -> False   # solid arm of the L
observable(cfg, 46, 55) -> True    # the notch: VISIBLE, and surrounded by mask
observable(cfg, 55, 55) -> False   # solid arm, right of the notch
observable(cfg, 30, 45) -> True    # outside the mask entirely
```

The notch at `(46, 55)` is the only point tested that is **visible while enclosed
by the mask on three sides**. That is the shape that makes "coverage, not area"
testable: the mask's area is large and its bounding box contains the event, but
the event is not covered.

## Arms

- **A — solid**: the default rectangle, event at `(46, 45)` inside it. The
  control, and it must tie (R-P1.9's single-observer result).
- **B — hole, event in the notch**: the parked-rectangle fixture above, kick at
  t=60 where the body is at `(46, 55)`. Predicted **unique**.
- **C — hole, event in the solid arm**: same mask, event at `(46, 45)`. Predicted
  **tie**, i.e. the mask still hides what it covers.
- **D — no mask at all**, event at `(46, 55)`. Predicted **unique**, and equal to
  B: a visible event is a visible event whatever surrounds it.

5 seeds each. The bodies and timings are identical across arms; only the mask and
the event position move.

## Frozen predictions

- **P1 — the control ties.** A gives ambiguity 2 on 5/5 seeds, reproducing
  R-P1.9's single-observer result, so the fixture is anchored.
- **P2 — the notch event is identified.** B is unique on 5/5 seeds.
- **P3 — the same mask still hides what it covers.** C ties on 5/5 seeds. A and C
  together are the load-bearing pair: identical mask, different event, different
  verdict.
- **P4 — the notch is indistinguishable from open space.** B and D agree on the
  verdict on 5/5 seeds. If they differ, the mask's presence changes something
  beyond coverage, and that would be a finding the lane has not seen.
- **P5 — the bounding-box statistic is not sufficient.** The mask's bounding box
  contains the notch event, so any rule keyed on "inside the bounding box" would
  call B hidden. Reporting B unique falsifies that rule explicitly.

Any prediction may fail and is kept.

## What this card may and may not conclude

- It **may** say whether coverage rather than area or bounding box decides the
  verdict for a mask with a hole, on this fixture.
- It **may not** claim a polygon estimator: R-P1.70 established that
  `BlindEstimate` is a rectangle, and this card computes the verdict with
  `attribute` from observations, not from the estimate.
- It **may not** generalise to masks with several holes, oblique edges, or a notch
  narrower than the body's step.
- `E6` stays closed.

## Controls and honesty

- Arm A anchors to a previously measured result; if it does not tie, the fixture
  is wrong and the run is `UNVERIFIABLE`.
- B and C share one mask and differ only in the event position, so the pair
  isolates coverage. D isolates the mask entirely.
- The receipt records `observable(...)` at all four probe points plus the event
  position for each arm, so the geometry claim is checkable rather than asserted.
- A mutation check: moving the parked first rectangle **onto** the notch must turn
  B into a tie. If it does not, the parking is not doing what the card claims.
- Verdict vocabulary: `PASS` / `FAIL` / `UNVERIFIABLE`.

## Limits

One L shape, one notch, one pair, five seeds, no noise. The notch is ~12 × 15
world units and the body moves 0.3 per step, so the crossing is well sampled; a
notch narrower than a step would be a different measurement.

**B and C are the pair R-P1.70 could not form**: one mask, two events, opposite
verdicts. So "coverage, not area and not bounding box" holds for a mask with a
hole, which is the rule R-P1.10 stated for rectangles.

The mutation check passed for the right reason: parking the first rectangle **on**
the notch turns it hidden and B becomes a tie (5/5), so the parking is what makes
the notch — not some other artefact.

### What this closes

R-P1.70's correction is now measured rather than merely stated, and the
reflex-mask question is answered for one shape: **an event inside a hole is
identified exactly as if the mask were absent**. Two limits are unchanged and
matter — `BlindEstimate` is still a rectangle, so this says nothing about
*estimating* a hole; and one L with one notch is not a theory of non-convex masks.

`E6` stays closed: a verdict, not headroom.
