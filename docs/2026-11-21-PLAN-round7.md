# Plan — the bounce-aware test: is the 0.67 ceiling model error or information loss? (2026-11-21, round 7)

Status: **PLAN**, written before execution. Predecessor: round 6.

## Why this is the decisive cheap experiment

Round 6 left one candidate A3 cell (ratio <= 0.4) where the best fully-covering
unfitted statistic is **0.67** against a 0.25 floor. Two explanations remain, and
they imply opposite decisions:

- **model error** — the statistics ignore a constraint the log actually carries,
  so a better unfitted estimator reaches 1.00 and no learned arm is needed;
- **information loss** — the observables genuinely do not contain the answer, so
  even the best estimator is bounded and a learned prior *might* recover it from
  statistics this instrument does not compute.

Neither has been measured. The log carries one constraint none of the current
statistics use: **observable wall bounces**. A ball that bounces between entry
and exit must leave with the post-bounce velocity, not the entry velocity.

## W1 — `v_bounce`: the constraint already in the log

For each match, take the last `wall_bounce` event between the entry and the exit
(it carries `side` and `v`), and score `|v_exit - v_bounce|`; when no bounce
falls in the interval, score `|v_exit - v_entry|` as the current statistics do.
Unfitted, one line of physics, no free parameters.

## W2 — measure it wherever the corpus has bounces

The parallel family bounces (measured in round 5's fixtures), so the statistic is
defined there. Report it beside the existing ones in all three cells from round 6
(`6/2`, `2/2`, `2/5`), with coverage (`decided`) alongside every number.

## W3 — the decision this produces

One of two sentences, whichever the numbers support:

- "at ratio <= 0.4 the best fully-covering unfitted statistic reaches X; a
  learned arm has no headroom" (X = 1.00), or
- "at ratio <= 0.4 no unfitted statistic, including the bounce constraint,
  exceeds Y; the remaining error is not model error" (Y < 1.00).

Either way the A3 registration question is answered with a number instead of a
recommendation. Not registered here; the operator decides.

## Gate

`scripts/statistic-survey.py` prints `v_bounce` with coverage; a test pins its
value in the cells measured, and asserts the experiment's premise — that bounces
actually occur inside the matched intervals (otherwise the statistic is vacuous
and the test must fail rather than pass silently).

## Execution status — 2026-11-21 (appended after measurement)

- **W1's premise is FALSE, and geometrically so.** Measured over the ratio-0.4
  corpus: **0 of 96** matched intervals contained a wall bounce, so `v_bounce`
  never executed its bounce branch and silently reduced to a velocity-continuity
  statistic (0.50, n=6). It *cannot* fire in this geometry: the occluder occupies
  x in [40, 60] and the walls are at x = 0 and 100, so a ball inside the occluder
  cannot touch a wall. The 1x2D "bounce while hidden" case this plan imagined
  does not exist here, and the statistic is dead code on this simulator.
  `test_bounces_can_never_fall_inside_a_matched_interval_in_this_geometry` now
  asserts the 0/96 fact, so the day the geometry changes the statistic stops
  being silently vacuous.

- **W3 answer: the second sentence, with a bound.** At ratio <= 0.4 no unfitted

  genuine information loss is **not resolved** by this round, and that is the
  honest state: the A3 registration would have to name ratio <= 0.4 and beat a
  measured 0.67 ceiling.
