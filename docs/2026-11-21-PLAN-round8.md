# Plan — the likelihood ceiling: is 0.67 information or model error? (2026-11-21, round 8)

Status: **PLAN**, written before execution. Predecessor: round 7.

## Why

Three rounds of unfitted statistics leave one number: at ratio <= 0.4 the best
fully-covering statistic is **0.67**, and no combination or extra constraint
beats it. Two explanations survive, and they decide A3:

- **model error** — a better estimator of the same observables reaches 1.00, so
  no learned arm is needed;
- **information loss** — the observables do not contain the answer, so 0.67 is a
  ceiling any arm inherits.

Neither has been measured. This round measures the **MAP world under an explicit
generative assumption**: for each enumerated world, the likelihood of the
observed boundary quantities given that world, with independent Gaussian error of
standard deviation `sigma = noise / sqrt(12)` (the SD of a uniform +-noise/2
sensor). MAP = the argmax world. That is the best decision available from these
observables *if* the error is Gaussian-shaped, so it separates the two
explanations for the family on which the question was posed.

## W1 — the oracle, stated as an assumption

`m2_map_accuracy(eps, noise, tol)`: log-likelihood per world =
`-sum(residual^2) / (2 sigma^2)` over three residuals per match (y continuity,
x continuity, velocity continuity), the same quantities the statistics use. No
parameter is fitted to the corpus; sigma comes from the sensor setting. The
assumption that uniform noise is Gaussian-shaped is **stated**, because a MAP
under the exact uniform likelihood is a feasibility set that ties, and a tie is
not a decision.

## W2 — measure the three cells

`6/2`, `2/2`, `2/5` (chance 0.25), same corpus builder as the survey, with
coverage. Report MAP accuracy beside the best single statistic.

## W3 — the sentence this produces

- MAP = 1.00 → model error; the next step is a better unfitted estimator, no arm.
- MAP <= 0.67 → the ceiling is information, and an A3 registration would be
  measuring an arm against a bar the observables cannot reach.
- in between (0.67 < MAP < 1.00) → partial information; the arm's target becomes
  "close the gap to MAP", with its own floor.

Recorded, not registered. Decision stays the operator's.

## Gate

`scripts/map-oracle.py` prints the table; a test pins MAP in each measured cell
and asserts the oracle cannot beat the exact-truth case (sanity: at noise 0, MAP
must equal the truth in every attributable episode).

## Execution status — 2026-11-21 (appended after measurement)

Three of my own model bugs surfaced while building the oracle. They are listed
first because they change what the earlier rounds' numbers mean.

1. **Residual off-by-one.** The enter position is logged at the last *visible*
   step (`t_enter - 1`) while the exit position is at `t_exit`, so the elapsed
   interval is `steps + 1`. Every x residual carried a systematic `v*dt` bias
   (0.3 units at v=3, dt=0.1 — 15% of the 2-unit separation). Fixed in all four
   sites; measurable proof: with noise 0 the true world's `rx` is exactly 0 at
   `steps+1` and exactly 0.3 at `steps`. Ranking was unaffected (the bias is
   constant per match), magnitudes were not.
2. **Support width was `noise/2` for a residual combining three attributes.**
   Propagated properly as `(noise/2) * sum|coefficients|`; the first version
   rejected every world.
3. **Velocity residuals need double support** (a difference of two independently
   noisy velocities); the first version also rejected every world.

## Measured

|---|---|---|---|---|
| 6/2 (ratio 3) | 1.00 | 1.00 (n=6) | **1.00 (n=4, tie 2, empty 0)** | 0.25 |

## The answer

- Where the exact sensor model **decides**, it is **always right** (1.00 at n=4
  and n=2): the observables are sufficient, and ties are the only failure mode.
- At ratio 0.4 the exact model **cannot distinguish any world**: all four are
  consistent with the readings in every episode. The 0.67 of the best statistic
  is therefore **not information** — it is a prior/surrogate artifact. The
  Gaussian surrogate manufactures a decision the true likelihood refuses, which
  is the cleanest demonstration in this repo that a likelihood choice can invent
  signal.
- **Consequence for A3:** the only cell where the residual looked weak is a cell
  where the observables carry no identity information at all. A learned arm there
  would learn this generator's quirks, not recover identity. GPU arms on M2 as
  constructed are **not justified** by these numbers. The informative regime is
  ratio >= 1, and there `|dy|` already scores 1.00.
- The honest open path is a *better instrument*, not a model: more crossings, a
  longer observation window, or a sensor that resolves the gap, so the
  likelihood stays discriminative at higher noise. That is a design decision for
  the operator, not something to slip in.
