## Observation boundary and predictions

- **X1 — capacity.** All 24 cells (`3 m × 4 s × 2 u`) produce a visible log
  with exactly one event, a right-side `exit_occ` at step 21. Its position
  is `(60.5, 50+d)` to absolute tolerance `1e-6` per coordinate. No earlier
  exit, corner entry, bounce, impact, or label is an alternative channel.
- **X2 — calibration.** At `u=2`, the magnitude channel returns `abs(d)` in
  integer millionths of a world unit, after six-decimal position
  quantization. Nominal support is `{1,3}` in world units; rival support is
  `{1.62,3.62,5.62,7.62}`. Both rivals have exactly the same support and
  frequencies. Expect **8/8** rival readings to reject nominal, **0/4**
  nominal false rejections. Each rival reading leaves the exact rival
  posterior uniform. Nominal-compatible and out-of-support are different
  cases; the latter never licenses a rival update. Unlike R-P1.47 these
  supports do not overlap. Do not infer robustness to noise from that gap.
- **X3 — diagnosis channels.** On independent reset enumeration, `passive`
  exposes signed `d` in millionths at `u=0`; `signed` exposes only `sign(d)`
  at `u=2`; `magnitude` exposes only `abs(d)` at `u=2`. The controller-facing
  sensor returns exactly one integer from the selected channel, never a
  raw event, source metadata, hidden state, or truth ID. Signed resolves
  **8/8** rival cases; passive and magnitude resolve **0/8** each. A
  balanced post-acquisition sign shuffle exchanges rival signs for
  `s=-3,-1` only; it preserves the sign counts and resolves **0/8** under
  the declared shuffled likelihood. Do not reveal the same-reset `s`.
- **X4 — boundary.** Missing, malformed, or extra visible events must not
  yield a reading. An unsupported probe or out-of-catalogue fixture input
  is refused before calling the simulator. Test the boundary with a
  synthetic event whose scalar differs from the analytic fixture and whose
  provenance contains a sentinel: the sensor must return the event-derived
  scalar only and must never request the oracle. The shape-only synthetic
  event is not an executed observation or a capacity measurement.
