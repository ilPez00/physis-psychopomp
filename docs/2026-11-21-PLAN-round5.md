# Plan — version truth, cross-process determinism, the A3 decision table (2026-11-21, round 5)

Status: **PLAN**, written before execution. Predecessor: round 4.

## What the check found

- **Version drift.** `pyproject.toml` and `psychopomp/__init__.py` say `0.1.0`;
  `CITATION.cff` and `REPRO.md` say `0.2.0`. Three surfaces, two answers, nothing
  comparing them.
- **No cross-process determinism gate.** The base RNG is int-only and safe, but
  the *scoring pipeline* was never run twice under different `PYTHONHASHSEED`.
  That is precisely how the noise-seed defect escaped: same inputs, 0.17 locally
  and 0.33 on CI. A within-process test cannot see it.
- **No lockfile.** `REPRO.md` tells the reader to `uv pip install -e '.[dev]'`
  without a lock, so "Python 3.12 pinned" covers the interpreter, not the deps.

## V1 — one version, checked

Declare `0.2.0` in `pyproject.toml` and `psychopomp/__init__.py` (the two
surfaces the package actually exports), keep `CITATION.cff` at 0.2.0, and add a
test asserting all three agree. Gate: the test fails if any surface drifts.

## V2 — the pipeline runs identically across processes

A test spawns the probe pipeline in two subprocesses with `PYTHONHASHSEED=0`
and `=1`, hashes the full report, and asserts equality. This is the gate for the
bug class CI caught, and it must be able to fail: a deliberately string-hashed
seed must break it (verified by hand, not shipped).

## V3 — the A3 decision table

The open decision is which task, if any, is worth a learned arm. Measure the
physics residual as the two balls are moved **closer** (separation 8 → 6 → 4 →
2 units) at fixed sensor noise (0, 2, 5): the band where the residual stops
being reliable is the candidate task. Report world counts too, because at small
separation the balls may genuinely collide and change the family.

Recorded as evidence. Not registered: registration needs operator sign-off.

## V4 — lockfile, bounded

Try `uv lock`; if it needs the network and fails, record the obstacle rather
than committing a hand-written lock. Gate: `uv lock --check` exits 0, or the
receipt says why not.

## Order and stop rule

V1 → V2 → V3 → V4. Two FAILs on one item: record and move on.

## Execution status — 2026-11-21 (appended after measurement)

- **V1 DONE.** `pyproject.toml` and `psychopomp/__init__.py` now say `0.2.0`,
  matching `CITATION.cff`; `test_the_version_is_one_answer_everywhere` reads all
  three surfaces and fails on any drift.
- **V2 DONE — and the first version of the gate was itself useless.** The
  pipeline it spawned built corpora at `noise=0`, so no jitter ever ran and the
  gate passed while the string-seeded RNG was present. Fixed by adding a noisy
  arm to the subprocess pipeline; mutation-checked properly: with
  `hash((seed, episode, "noise"))` restored, the gate FAILS; with the int-only
  seed it passes. Two subprocesses, `PYTHONHASHSEED=0` and `=1`, byte-identical
  reports required.
- **V3 DONE.** Separation sweep, 6 episodes per cell, chance 0.25:

  | separation | noise 0 | noise 2 | noise 5 |
  |---|---|---|---|
  | 8 | 1.00 | 0.83 | 0.33 |
  | 6 | 1.00 | 0.67 | 0.33 |
  | 4 | 1.00 | 0.33 | 0.33 |
  | 2 | 1.00 | 0.33 | 0.33 |

  The ratio is what decides: `sep/noise ≥ 4` → 0.83, `= 3` → 0.67,
  `≤ 2` → the 0.33 plateau. Exact positions are unaffected by separation at all
  (1.00 everywhere), so the physics residual is only limited by sensor
  resolution relative to the gap it must resolve.
  **Design consequence for A3:** a task worth a learned arm needs
  `sep/noise ≤ 2` — exactly the cell where the residual is stuck at 0.33 and
  its confidence was already measured as uninformative (round 4).
- **V4 DONE.** `uv lock` resolved 14 packages; `uv.lock` committed, `uv lock
  --check` added to CI and to REPRO's install steps.
- `per-round test count`: **61**.

**Not done, and deliberately:** no A3 registration, no learned baseline. The
table above is the evidence the registration decision needs; making that
decision is the operator's, and a hand-rolled classifier would be a new claim
with no review.
