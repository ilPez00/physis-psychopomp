# Plan — R-P1.3 camera-layer degradation (2026-11-21, before execution)

Status: **PLAN**, written before the measurement. Roadmap: `docs/ROADMAP.md`
R-P1.3. Predecessors: R-P1.1 operating point (sep=6, noise 1.0 Bayes / 0.5
A2 channel), R-P1.2 frames (`psychopomp/perspective.py`).

## Why

A4 (the perspective experiment) will compare frames under degraded observation.
Before that, the degradation layer has to exist and its effects must be
measured, not assumed: quantization, sensor jitter, missing auxiliary
observations. Identity ambiguity needs no code — the observable log carries no
labels by construction — and that absence is asserted, not implemented.

## Predictions (fixed now)

- **P1** — the A2 position probe degrades with grid quantization as `q`
  approaches the lane separation (6 units): top-1 falls from 1.00 at q=0
  toward chance as `q → 3`, and is at/below chance for `q ≥ 4`.
- **P2** — independent per-attribute jitter at the operating point reduces the
  exact-Bayes decided count monotonically (ties rise); accuracy among decided
  episodes stays 1.00 (the decision is conservative).
- **P3** — dropping auxiliary events (`wall_bounce`, `kick`) leaves the EC
  world count and `truth-in-worlds` unchanged: the filter reads only
  `enter_occ`/`exit_occ` times and velocities.
- **P4** — smooth jitter is frame-invariant between `world` and `random:1`
  (rotation + drift preserve distances and relative velocities). Grid
  quantization is **frame-dependent** (a grid does not commute with rotation);
  differences there are reported, not treated as bugs.

If P1 improves with coarsening, or P3 changes the enumeration, something reads
auxiliary events: that is a finding before any cell is interpreted.

## Instrument

- Corpus: parallel lanes, `sep=6, noise=1` (R-P1.1 operating point), 6
  attributable episodes.
- Degradations (`psychopomp/camera.py`, observable log only, seeded):
  `quantize ∈ {0, 0.5, 1, 2, 4}` at jitter 0; `jitter ∈ {0, 0.5, 1}` at
  quantize 0; one combined cell (1, 0.5).
- Frames: `world` and `random:1` (R-P1.2), applied **before** degradation.
- Metrics: worlds mean, exact-Bayes decided/tie, Bayes top-1, A2 position
  top-1, truth-in-worlds.

## Gate

`scripts/degradation-matrix.py` prints the table; tests pin: quantization
lands on the grid, jitter bounded and deterministic, aux-drop preserves the EC
enumeration, and no degradation introduces identity labels. Not a registered
claim.

## Execution status

tolerance and the Bayes model both use the **summed error support**
(sensor + quantization + jitter). That was a measurement bug found first: with
`tol` pinned at the sensor noise, every jittered cell read "no consistent
world" — cells were under-toleranced, not information-free.

Readings:

- **Enumeration is invariant** to every degradation: worlds 4.00 and
  truth-in-worlds 6/6 in all cells. The filter stays sound; only decisions
  move. (P3 upheld: dropping all auxiliary events changes nothing — the filter
  reads only enter/exit.)
- **P2 upheld**: decided count falls monotonically with jitter (6, 4, 1, 0, 0
  at j = 0, 0.5, 1, 2, 3) and accuracy among decided episodes stays 1.00.
  The boundary is jitter ≈ separation/2, matching R-P1.1's ratio story.
- **P1 FALSIFIED**: grid quantization does **not** degrade the A2 position
  probe in world coordinates (1.00 even at q=4) — lanes are 6 apart, so
  quantizing to a grid does not destroy their y-ordering.
- **P4 half-falsified**: the Bayes/EC arms agree between world and random:1
  up to sampling (4 vs 2 decided at j=1 on 6 episodes; single-realisation
  difference, a seed sweep would settle it — noted, not claimed). But the
  **A2 position probe is axis-bound**: 1.00 in world vs 1.00→0.33→0.00 in a
  rotated frame. A2's 1.00 is a property of the *probe reading the y axis*,
  not of the information. A4 must either use a rotation-invariant residual or
  re-register A2 per frame; the current probe cannot be compared across
  frames.

Instrument consequence: the A4 baseline for each frame is the exact-Bayes arm
at the summed support, never the y-residual probe across frames.
