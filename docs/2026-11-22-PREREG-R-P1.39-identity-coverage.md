# PREREG — R-P1.39 identity is coverage-gated too (2026-11-22)

Status: **registered before the run**; claim registered in the store before the
run. Roadmap `docs/ROADMAP.md` R-P1.39.

The last P1 axis. Everything so far asked *what happened*; this asks *who*. The log
is identity-free by design, so a relabelling of two identical bodies is — by
construction — invisible in it. That is a tautology, not a finding, **unless the
observer has some identity evidence and that evidence is itself coverage-gated**.
This card adds exactly that and tests whether identity follows the same rule as
events.

## Instrument

`SimConfig.identity_marker: bool = False` — when on, every body emits an observable
`marker` event every `marker_period` steps (default 10) **while it is visible**,
carrying its tag (`"A"`/`"B"`). Off by default, so every prior number is unchanged.

Two bodies, one world, and its **relabelling**: the same trajectories with the tags
exchanged. If the observable logs of the two are identical, identity is
unidentifiable; if they differ, the tag has been seen.

## Cells

`o = (40,60,35,65)`, task-free; four cases:

1. **no marker, visible bodies** — `o2 = (46,54,35,65)`, both bodies cross the open
   parts of the box;
2. **marker, visible bodies** — same world, markers on;
3. **marker, hidden bodies** — `o2` widened to `(30,92,20,90)` so that the blind set
   is the whole of `o` **and** the bodies' whole paths lie inside it: markers are
   enabled but can never be emitted;
4. **marker, hidden bodies + second observer that sees them** — `o2` narrow again so
   a second vantage exposes the paths.

## Predictions (fixed now)

- **M1 (the tautology, measured).** Without markers the relabelled world's
  observable log is **identical** to the original's (same events, same values,
  same order) — so identity is unidentifiable, and this is measured on real logs
  rather than argued.
- **M2 (a marker resolves it).** With markers on, the two logs **differ**, and the
  difference is in `marker` events only: the tag moves to a different trajectory.
- **M3 (identity is coverage-gated).** With markers on but the bodies' paths
  entirely hidden, **zero** `marker` events are emitted, and the relabelled logs are
  identical again: identity ambiguity persists because the *evidence* is occluded,
  not because identity is special.
- **M4 (so the same fix works).** Restoring visibility (case 4) brings the markers
  back and the ambiguity resolves — the coverage lever moves identity exactly as it
  moves events.

## Prior

**0.9** for M1/M2 (the instrument is deterministic and markers are emitted while
visible). **0.7** for M3/M4: they require the bodies' whole paths to be inside the
blind set, and the blind set is bounded by `o`, so a path that starts outside `o`
would leak a marker. The card declares the geometry to avoid that (bodies start
inside `o`), which is itself a design constraint worth stating.

## Rules

- No retune. A falsified prediction is a receipt.
- Marker period, geometry and the four cases are declared here.
- No learned arm, no noise: this is an information question, not a statistical one.

### The finding, and the defect under it

> **Identity is coverage-gated exactly as events are.** Ambiguity is not a property
> of identity but of whether evidence about it was ever observed — which is the same
> lever the law describes for events, applied to a different kind of evidence.

Getting there exposed a **leak the program had not noticed**: the observable log is
appended in *body-index order*, so a relabelling changes the event **sequence**
(column 3 of the table) even when every event is identity-free. An observer that
receives the log as a sequence can therefore distinguish worlds it should not. The
export contract (`psychopomp.observation/1`) now sorts canonically so the channel
never reaches a consumer, and a test pins it (`test_a_relabelling_exports_identically`).
The raw `EventLog` still has that order — named here rather than silently fixed,
because changing it would move every pinned export.

Second defect, caught by M3: the initial visibility flag was hardcoded `True`, so a
body that started occluded was reported visible for one step and emitted a marker
for a body never seen. Now computed.

### Limits

Two bodies, one marker cadence, three geometries, stationary bodies in the hidden
case (a moving body leaves `o` at the walls and becomes visible — the geometry, not
the instrument). Markers are perfect when present; a *noisy* or partial marker is
not modelled, and would need the R-P1.35 treatment.
