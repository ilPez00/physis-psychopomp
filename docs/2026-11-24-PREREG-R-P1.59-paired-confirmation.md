# Preregistration — R-P1.59: same-episode confirmation

Claim `87b40982-f133-4e94-92d4-111cde3457a2`. Prior **0.5**.
Freeze on origin before implementation or measurement. Status at freeze:
**not measured**. This is a follow-up to R-P1.58, not a revision of it.

## Fixture

Four equiprobable modes per mechanism. First readings are R-P1.58's
overlap channel. The second channel deliberately preserves the same
unconditional marginal in all mechanisms; only the within-episode
pairing changes. The policy catalogues only the two known laws.

| Mechanism | First reading by mode | Confirmation by mode |
|---|---|---|
| Known negative | −2, −2, −1, +1 | 0, 1, 2, 3 |
| Known positive | +2, +2, −1, +1 | 0, 1, 2, 3 |
| Unseen mimic | 9, 9, +2, +2 | 0, 1, 2, 3 |
| Unseen equivalent (separate stress arm) | +2, +2, −1, +1 | 0, 1, 2, 3 |

Budget is at most two unit-cost acquisitions. First read once. Stop with
no declaration on an ambiguous or unsupported first reading. At budget
one, the strict policy also withholds a unique match pending confirmation.
At budget two, only a unique match triggers one confirmation. Declare it
only when the observed pair is in that law's **conditional** support; if
not, report mismatch, not the opposite law. No retry. The policy sees
readings, not mechanism or mode. The equivalent stress arm has no recoverable
distinction on these probes by construction.

## Frozen checks

- **P1 — capacity first.** Each confirmation multiset is `[0,1,2,3]`.
  In the main 12 cases there are six unique first matches, four ambiguous
  and two unsupported. Stop before scoring if capacity fails.
- **P2 — matched first shot.** At budget one, the R-P1.58-style control
  declares four correctly and two falsely; the confirmation-required
  policy declares none. Both acquire exactly 12 times.
- **P3 — paired, budget two.** Four known cases declare correctly; the
  two eligible mimic cases flag mismatch; the remaining six stop on the
  first reading. Zero false declarations, 18 acquisitions over 12 cases.
- **P4 — fresh-reset, matched cost and marginal.** For each of the 12
  first-shot cases enumerate all four equally weighted independent reset
  modes for the second channel. At the same mean cost of `3/2` per case,
  recover **8/16** eligible known cases and falsely declare **4/8**
  eligible mimics; six first-shot stops are repeated four times.
  This control uses the same confirmation rule, but pairing is broken.
- **P5 — observational equivalence.** Run the unseen equivalent separately
  at budget two: **2/2** eligible confirmations falsely declare positive;
  the other two cases stop ambiguous. This is a failure witness, not evidence
  that the second probe rules out all unseen mechanisms.
