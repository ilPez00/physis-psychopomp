# PREREG — R-P1.24 hedging against your own self-model (2026-11-22)

Status: **registered before the run**. Roadmap `docs/ROADMAP.md` R-P1.24.
R-P1.21 measured the cost of a wrong self-model (up to 3 of 4 task events) but
gave the observer no defence. The obvious defence is to plan against the
possibility of being wrong. This card measures whether it pays, and what it
costs.

## Design

Same world as R-P1.21 — `o = (40,60,35,65)`, `o2 = (46,54,35,65)` (a narrow
window that can be *relocated* inside `o`), task events at `x ∈ {42,46,48,52}`,
`y = 45`, `t* = 90`, one body per task point, drifts
`v ∈ {−1, −0.5, 0, +0.5, +1}`.

Three planners over that drift grid:

- **naive(δ)** — plans from the belief that its occluder sits at `o2 + δ`, exactly
  as R-P1.21 did. Its measured score is a function of the true error;
- **hedged** — knows its belief may be off by at most 20 units in either
  direction, and picks the drift maximising the **minimum** predicted score over
  `Δ = {−20, −10, 0, +10, +20}`. One plan, chosen without knowing δ;
- **oracle** — the best drift measured on the true world (upper bound, not
  available to the agent).

Measurement is R-P1.21's: the chosen drift is run under the true `o2` and each
task event is scored tie/unique by counterfactual attribution.

## Predictions (fixed now, using R-P1.21's measured naive scores 4,1,2,2,2)

- **H1 (hedging beats being wrong).** The hedged plan's measured score is
  **≥ 2/4**, strictly above the naive planner's worst case (**1/4**, at δ = −10).
- **H2 (hedging is not free).** The hedged score is **≤ 4/4** and its regret
  against the oracle is **≤ 2 task events** — a hedge that costs more than half
  the task set would not be worth recommending.
- **H3 (it is a real hedge, not a coincidence).** The hedged drift differs from
  the δ = 0 naive choice (`+1.0`), i.e. the plan actually changes when uncertainty
  is acknowledged.
- **H4 (consistency with the law).** For the hedged drift, the measured score
  equals the count of task points predicted identifiable under the **true**
  geometry — the hedge changes the plan, never the rule.

## Prior

**0.6.** H1/H4 follow from the law and should hold; H2 is the open question — a
minimax over a ±20 unit belief set may well pick a drift that is mediocre for
every δ, and the hedge could cost the full 2 events or more. H3 could fail if the
minimax happens to coincide with the confident choice, which would mean hedging
is free *because* it is unnecessary in this geometry.

## Rules

- No retune. A falsified prediction is a receipt.
- One belief set `Δ` and one drift grid, both declared here; no widening after
  the result.

## Execution status — run 1, 2026-11-22: all four UPHELD

| drift | measured |
|---|---|
| −1.0 | **3/4** |
| −0.5 | 1/4 |
| 0.0 | 2/4 |
| +0.5 | 3/4 |
| +1.0 | 4/4 (oracle) |

| planner | drift chosen | measured |
|---|---|---|
| naive δ = −20 | 0.0 | 2/4 |
| naive δ = −10 | −0.5 | **1/4** (worst case) |
| naive δ = 0 | +1.0 | 4/4 |
| naive δ = +10 | 0.0 | 2/4 |
| naive δ = +20 | 0.0 | 2/4 |
| **hedged** | **−1.0** | **3/4** |
| oracle | +1.0 | 4/4 |

- **H1 UPHELD** — the hedged plan scores **3/4** where the worst naive plan scores
  **1/4**: minimax over a ±20 unit belief set recovers two of the three events a
  wrong self-model loses.
- **H2 UPHELD** — regret against the oracle is **1 event**. Hedging is not free
  and it is affordable: three quarters of the task set without knowing which way
  the model is wrong.
- **H3 UPHELD, and the interesting part** — the hedge picks **−1.0**, the
  **opposite** drift to the confident choice (+1.0). An observer that
  acknowledges uncertainty does not simply take its best guess more carefully; it
  moves in the other direction, because the maximin of a shifted blind window is
  not a shrunk version of the confident optimum.
- **H4 UPHELD** — the hedge changes the plan, never the rule: predicted
  identifiable under the true geometry equals measured, exactly.

### The finding

> Uncertainty about your own blind spot is not a reason to observe less — it is
> a reason to move differently. A hedged plan over a declared belief set
> recovered 3 of 4 task events where a confidently wrong plan kept 1, at a cost
> of 1 event against an oracle that knows the truth.

### Limits

One world, one belief set (±20 units), one task time, one drift grid, noise-free,
and the hedge is a hardening rule (minimax) rather than a probabilistic model:
the card measures a policy's *outcome*, not a decision-theoretic optimum. A
Bayesian planner with a prior over δ is the natural next card and is **not**
claimed here.
