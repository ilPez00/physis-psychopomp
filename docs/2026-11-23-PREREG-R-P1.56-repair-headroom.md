# Preregistration — R-P1.56: repair headroom before any learner (2026-11-23)

Claim `c4847c84-a694-43e6-a5f3-a3db19875602`. Prior: **0.5**. Freeze on origin
before running. Status at freeze: **not measured**.

Operator-requested learner is gated by this card. E6 in the [plan](../../tasks/plan.md)
allows a ranker "only if E3 leaves measured headroom", and the standing learner
stop rule requires a named deterministic baseline and a shuffled control that
loses. This card measures the baseline; it trains nothing.

## The question

On worlds where the observations genuinely cannot decide the graph, how much
correct repair does a deterministic policy recover, and does anything remain
for a learner to win?

"Recover" is scored against a **truth the observations never saw**. The decoder
receives partial observations only; the true edge set exists in the fixture and
is used only by the scorer. Feeding the decoder the truth is the failure mode
this card exists to detect, and R-P1.52 is the precedent where the candidate
set contained the answer.

## Fixture

Synthetic worlds, one seed per case. Each world is `n = 8` entities of two
kinds (`node`, `port`) and a true edge set of `m = 6` `LINK`s drawn from the
kind-admissible pairs (`node→node`, `node→port`), no duplicates, no
`port→port`.

Observation reveals, per case, a frozen subset:

- every entity id (so the entity set is known and candidates are only edges);
- `k = 3` of the 6 true edges, plus nothing false.

A **candidate world** is any edge set of size 6 that contains the 3 observed
edges. The surviving set is the candidate worlds that also satisfy the declared
closure rule: no entity exceeds in-degree 2 or out-degree 2. Every case must
leave **at least 2** surviving worlds; a case with one survivor is
**determined** and is reported as such, not scored.

The decoder under test is the existing `psychopomp.graph_patch.decode` over the
surviving worlds, unchanged.

## Arms (all on the same cases, same observations)

- **A — no repair:** propose nothing.
- **B — consensus only:** propose an edge only when every surviving world
  contains it; abstain otherwise.
- **C — support rank:** propose the top-3 edges by number of surviving worlds
  containing them, ties broken by `(source, predicate, target)` ascending.
- **D — shuffled:** arm C with the truth labels permuted across candidates
  within a case, 200 permutations, mean reported.

The learner is **not** run here. If it ever runs it is arm E, offline, scored on
the same held-out cases, and only after this card's verdict.

## Predictions (fixed now)

- **H1 — the cases are genuinely ambiguous.** Every scored case has at least
  2 surviving worlds, and the fraction of *determined* cases is below **0.5**.
  If this fails the fixture is too easy and the card is **VACUOUS**, not a
  win for any arm.
- **H2 — consensus is precise but small.** Arm B's precision is **≥ 0.9** and
  its recall is **< 0.6**: agreement survives only where the closure rule does
  the work, so B is safe and nearly useless.
- **H3 — support rank trades precision for recall.** Arm C's recall is **≥ B's
  recall + 0.1** and its precision is **≥ 0.5**; it is the arm a learner must
  beat.
- **H4 — shuffling destroys the signal.** Arm D's precision is **≤ 0.25**,
  which is chance for 3 draws from the surviving candidate pool.
- **H5 — headroom verdict follows H2–H4 mechanically.** Headroom exists only
  if H2 and H3 and H4 hold *and* C's precision leaves at least **0.1** of
  reachable precision unused at its recall. Otherwise the card records
  **no headroom** and E6 closes without a learner.

## Rules

Split by world seed: **24 cases, 12 development and 12 held-out**, drawn before
any feature is extracted. Report development and held-out separately; a
held-out number that beats development is a reason to look, not a result.

Metrics per arm: precision, recall, false corrections (proposed and not in the
truth), abstentions, and determined-case share. Every metric prints its
denominator.

No arm gets a different candidate set, a different closure rule, or a different
observation budget. If any prediction fails, it is recorded as failed; no
threshold is retuned and the card is not re-run against a moving fixture.

## Limits

- Synthetic graphs only: `LINK` between two kinds, one closure rule. Nothing
  here transfers to a real repository graph without its own card.
- The closure rule is a *declared* prior, not a measured one. A different rule
  changes the surviving set and every number above.
- Precision and recall over candidate edges say nothing about whether a repair
  is *safe* to write. The writer's evidence and approval boundary
  ([rollout](../notes/production-repair-rollout.md)) is a separate gate, and a
  learner never holds it.

## Execution status — run 1, 2026-11-23: **PASS, verdict `NO HEADROOM`**

Frozen and pushed before the run. `scripts/repair-headroom-prereg.py`, 24 cases
(12 dev, 12 held-out), 0 determined.

| arm | held-out precision | held-out recall | false corrections |
|---|---|---|---|
| A no repair | 0.000 | 0.000 | 0/0 |
| B consensus only | 0.000 | 0.000 | 0/0 (12 abstentions) |
| C top-3 by support | 0.194 | 0.097 | 29/36 |
| D C vs permuted truth | 0.282 | — | — |

- **H1 UPHELD** — 0/24 determined, every case has at least two surviving worlds.
  The fixture is genuinely ambiguous, so the run measured something.
- **H2 FALSIFIED** — consensus proposes *nothing*. With three of six edges hidden
  and only a degree cap as closure, no unobserved edge is present in every
  surviving world.
- **H3 FALSIFIED** — C reaches recall 0.097 against B's 0.000, short of the 0.1
  bar, at precision 0.194 well under 0.5.
- **H4 FALSIFIED, and this is the finding.** The shuffled arm scores **0.282**,
  *above* the real arm's 0.194. Ranking by "how many surviving worlds contain
  this edge" is not weak here: it is **worse than chance**. Top-supported
  candidates are the ones that complete many *other* worlds, which is a
  property of plausible completions, not of the truth.

Consequence, recorded rather than retuned: at this observation budget the
candidate set carries no recoverable ranking signal that support counting can
reach, and a learner trained on those same features would fit noise. E6 stays
closed. Any future learner card must add information the surviving-world counts
do not already contain (domain features), and must beat chance before it is
described as headroom.

Known limit of this reading: one fixture, one closure rule, one observation
budget (3 of 6). The negative is about *this* budget, not about repair ranking in
general — but it is the only measured statement, and the gate pins it.
