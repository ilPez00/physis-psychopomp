## What R-P1.43 claimed without measuring

R-P1.43's **Amendment 1** replaced the instrument it had first described — a late
report carrying the **stale position** — with a lagging sampler that reports the
body's position at `t + L`. The amendment says the stale-position story is a
**null instrument**:

> "the estimator reads positions, and ordering was already canonicalised in
> R-P1.39, so it would change nothing and the predictions below would be
> falsified for a reason unrelated to latency."

That is a reasoning claim, not a measurement. The card then measured only the
lagging sampler. **This card measures the other one** and asks whether the
amendment was right.

## The two instruments, stated exactly

- **lagging sampler** (`R-P1.43`, measured): a crossing at step `t` is reported
  at `t + L` carrying the position **at `t + L`**.
- **true delay** (this card): a crossing at step `t` is reported at `t + L`
  carrying the position **at `t`** — the report is late, the content is old.

Only the second is "the sensor reported late". The first is "the sensor was
sampled late", which is a different physical story and is why the arm needs its
own measurement rather than an argument.

## Fixture and arms

R-P1.43's world and corpus, unchanged: `o2 = (46, 54, 35, 65)`, `dt = 0.3`, five
horizontal lanes × three vertical columns, `L ∈ {0, 1, 2, 3}`. Three arms on
**identical** episodes:

- **A — no delay** (`L = 0`), the baseline that must reproduce R-P1.43's `L = 0`.
- **B — lagging sampler** (R-P1.43's instrument), re-measured here so the two are
  compared under one harness rather than across two cards.
- **C — true delay** (stale position), this card's question.

## Frozen predictions

- **P1 — the amendment's premise is testable and it is right about ordering.**
  Position *values* are what the estimator reads, and event ordering is
  canonicalised (R-P1.39), so C must not change the **ordering** of the
  estimator's inputs. Checked directly: the sorted position sequence under C
  equals A's for `L ≥ 1`. If C reorders anything, the amendment's reasoning was
  wrong about the mechanism.
- **P2 — but C is not null anyway.** The estimator's one-step bound is computed
  from positions that are now `L` steps stale, so the **edge estimate** must
  differ from A on at least one of the four lags, measured as bound error, not as
  ordering. Predicted: C degrades like B on the estimate while differing in the
  event time.
- **P3 — the two instruments are distinguishable.** There exists at least one
  `(lane, column, L ≥ 1)` cell where B and C produce **different** reported
  positions. If they never differ, one of the instruments is not implemented —
  the failure mode R-P1.43's amendment risked.
- **P4 — identifiability is untouched by either.** The tie/unique verdict is a
  predicate on the **true** event location, so A = B = C on 5/5 seeds at every
  lag. This restates R-P1.43's law clause for the instrument the amendment
  dropped.
- **P5 — no oracle leakage.** Neither delayed instrument may change the oracle
  log; the oracle event time and position must be identical to A in every cell.

Any prediction may fail and is kept. **P3 failing would mean this card cannot
answer its own question**, and would be reported as `UNVERIFIABLE` rather than as
evidence for the amendment.

## What this card may and may not conclude

- It **may** say whether R-P1.43's null-instrument claim was correct, and it may
  **retract the amendment's reasoning** while leaving R-P1.43's measured numbers
  exactly as they are.
- It **may not** retune R-P1.43's thresholds, cells or receipt. That card measured
  the lagging sampler; this one measures a different instrument.
- It **may not** claim latency robustness in general: one geometry, one corpus,
  four lags, no noise beyond what the corpus carries.
- `E6` stays closed; no learner, no headroom.

## Controls and honesty

- Arm A is the identity control and must reproduce R-P1.43's `L = 0` cell.
- Arms B and C run on the **same episodes and seeds**, so any difference is the
  instrument.
- The receipt prints, per cell, the reported position under each arm, so P3 is
  checkable rather than asserted.
- A mutation check: forcing C to carry the fresh position (making it equal B)
  must fail P3. If P3 still passes, the check is not measuring the instrument.
- Verdict vocabulary: `PASS` / `FAIL` / `UNVERIFIABLE`.

## Limits

One geometry, four lags, deterministic estimator, no sensor noise. The corpus's
lanes are horizontal, so a stale position moves *along* the lane and the vertical
excursion is small by construction — a corpus with oblique lanes would exercise
the instrument harder, and is a follow-up rather than a claim here.

### What this means

**R-P1.43's Amendment 1 was correct and I was wrong to predict otherwise.** The
estimator reads *positions*; a report that is late but carries the position it
observed is therefore invisible to it. The lagging sampler moves the estimate
because it reports a *different* position (`0.200 → 0.050 → −0.250 → −0.550`),
not because it is late.

The distinction matters for what the two instruments can test: a stale-position
delay would need a consumer that reads **timestamps** to have any effect, and
nothing in this lane's estimator does. P3 held — the instruments *are* different
as logs — so this is not the "one instrument is unimplemented" failure the card
guarded against.

### What changes, and what does not

- R-P1.43's measured numbers stand untouched; only its *reasoning* is now
  measured rather than argued, and it holds.
- D4 in the execution queue is closed: "true delay versus outward sampler" is
  answered — the true delay is null **for this estimator**, and that is a
  statement about the estimator, not about latency in general.
- The honest next question this raises is not another delay arm but a consumer
  that reads event *time*: no current surface does, so a delay story has no
  place to land yet. Recorded rather than built.

### Limits

One geometry, four lags, twenty corpora, deterministic estimator, horizontal
lanes. A stale position moves along the lane, so the vertical excursion is small
by construction — but the result is exact (`0.200` to twelve decimal places),
not marginal, so the corpus shape is not what produced it.
