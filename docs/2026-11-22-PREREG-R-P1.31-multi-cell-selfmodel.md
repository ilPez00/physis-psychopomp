# PREREG — R-P1.31 multi-cell self-models, and the structural prior (2026-11-22)

Status: **registered before the run**; claim registered in the store before the
run. Roadmap `docs/ROADMAP.md` R-P1.31.

R-P1.29's estimator returns **one** rectangle, while the law (R-P1.25) covers blind
sets that are a **union**. R-P1.30's capstone is therefore untested on non-convex
geometry. This card extends the estimator to `n_cells` rectangles and asks a
question the earlier cards could not: **what does it cost to be wrong about how
many blockers you have?** That is a *structural* prior about one's own hardware,
not a geometric error — a different failure mode from R-P1.21's ±20 unit offset.

## Instrument

`estimate_blind_cells(episodes, step, n_cells)` — clusters the crossing bounds
into `n_cells` x-intervals, pairs each left-entry cluster with the next right-exit
cluster, and assigns `y` edges by whether a crossing's `x` lies inside the cell.
The observer is told `n_cells` (it owns the hardware). If the evidence does not
support the claimed count, it **abstains** — every cell returned unknown — rather
than inventing geometry.

## World

Islands on one lane band: `o = (40,60,35,65)`, extra blocker `(70,78,35,65)`,
second observer `o2 = (44,84,20,90)`, so the blind set is
`(44,60,35,65) ∪ (70,78,35,65)` when static — two cells with a **gap at 60–70**.

- corpus: horizontal bodies crossing both cells (lanes 38–76) plus vertical
  bodies inside each cell, one mover per episode with a parked partner;
- task points: `x ∈ {42, 44, 65, 74}` on lane `y = 45` — one outside the blind
  set, one on its left edge, one **in the gap**, one inside the island;
- drifts `v ∈ {−1, −0.5, 0, +0.5, +1}`, `t* = 90`, one body per task.

## Predictions (fixed now — comparisons, not transcribed numbers)

- **P1 (both cells are recovered).** The two-cell estimate recovers both cells,
  each **contained** in its truth and within **one step** on every recovered edge.
- **P2 (the gap is known to be visible).** The two-cell estimate predicts the gap
  point `(65, 45)` **identifiable**; a single-cell estimate cannot represent the
  gap, so it must treat that point as blind or unknown.
- **P3 (the two-cell agent plans optimally).** Calibrated with `n_cells = 2`, the
  agent's chosen drift reaches the **oracle score** on the task set.
- **P4 (a wrong structural prior costs).** The same agent calibrated with
  `n_cells = 1` (it believes it has one blocker) scores **strictly lower** than
  with `n_cells = 2` on the same task set. That is the cost of being wrong about
  one's own structure, and it is a failure mode the geometric-error cards cannot
  produce.

## Prior

**0.75** for P1/P2 (the clustering is exact on noise-free bounds and the geometry
is separated by 10 units, far above the 0.3 tolerance). **0.6** for P3/P4: the
planning consequences depend on which drifts move the cells off which tasks, and
that interaction is exactly where my last four predictions were wrong.

## Rules

- No retune. A falsified prediction is a receipt.
- One world, one corpus, one task set, `n_cells ∈ {1, 2}` — declared here.
- The single-cell agent is given the **same corpus**, so the difference isolates
  the structural prior, not the evidence.

### The unifying finding

All self-model errors measured in this instrument are **optimistic**:

- geometric (R-P1.29): the estimate is a *subset* of the truth — under one step it
  under-reports blindness;
- structural (this card): a wrong cell count **drops a cell**, again under-reports.

So an observer's mistakes about itself go in exactly one direction: it believes it
is **less blind than it is**, never more. That is a property of learning a boundary
only where something crossed it, and it now holds across both kinds of self-model
error — geometric and structural.

### Limits

Two cells, ordered along `x`, disjoint, one lane band, noise-free. The clustering
assumes disjoint ordered cells (declared); overlapping or nested blind cells are
out of scope. `n_cells` is *told* to the observer, which is the point of P4 — the
structural prior is the variable — but an observer that must *estimate* its own
blocker count is not attempted here.
