# Preregistration — R-P1.53: admission of decoder proposals (2026-11-23)

Claim `34f72429-d5aa-461d-89cf-2ec5a6ac2ddf`. Prior: **0.85**. Freeze on origin
before running. Status at freeze: **not measured**.

This is E4-partial: the first path where a Psychopomp proposal reaches a writer.
The writer is `physis declare`, and the point is that **admission is the fold's
decision, not the decoder's** — the decoder never calls it, and a proposal's
confidence never enters the decision.

## Setup

Fresh scratch world (not this repository, not a shared world): two text files,
`physis observe`, then a snapshot parsed by `psychopomp.physis_snapshot`. Four
probes, each one `physis declare` invocation, observed by exit code and by the
observation-log length before/after.

`E` = `file:src/a.txt --CONTAINS--> file:src/b.txt` (measured in E0 to have no
lane), `U` = the same pair with predicate `frobnicates` (not in the vocabulary),
`O` = `file:src/a.txt --DEFINES--> document:src/a.txt::1` (already observed).

## Predictions (fixed now)

- **P1** declaring `E` returns **1** (refusal) and **grows the log by one row** —
  a refusal is recorded, not discarded.
- **P2** declaring `E` again returns **3**, not 1: the refusal names the row that
  earned it, so a repeat is `UNVERIFIABLE`. This is the E0 finding, and a repair
  loop that retries until `0` would spin.
- **P3** declaring `U` returns **2** and the log **does not grow**: invalid input
  writes nothing.
- **P4** declaring `O` returns **0** and the object's incident relations stay at
  **1**: admitted-or-already-declared is idempotent for the graph, even though the
  log grows.
- **P5** in every probe the decoder's own output is unchanged: status
  `HYPOTHESIZED`, `verifier.status = NOT_EVALUATED`, and the plan's
  `base_revision` equals the snapshot's. Nothing the decoder emits claims an
  admission.

## Rules

A probe whose exit code differs is reported as written; no probe is re-run to a
different outcome, and no predicate is swapped to make P1 pass. If `physis` is
absent, the card is **NOT MEASURED** and says so.

## Limits

- One world, one ontology version (`physis` 1.9.1). Admission rules are not
  inferred beyond the four probes.
- `E`'s refusal is evidence about *this* ontology's lanes, not about the decoder.
- The card does not test `removed:rel|…` or `as-of`; both stay unverified from E0.
