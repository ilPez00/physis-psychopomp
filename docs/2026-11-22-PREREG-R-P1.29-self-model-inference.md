# PREREG — R-P1.29 can an observer recover its own blind spot? (2026-11-22)

Status: **registered before the run**; claim registered in the store before the
run. Roadmap `docs/ROADMAP.md` R-P1.29.

R-P1.21 measured what a wrong self-model costs, R-P1.28 that the cost is a cliff
at certainty. Neither asked the question underneath: **can the observer fix the
model?** Its only evidence about its own blind region is its own observable log —
events it saw, and the places where it stopped seeing.

This card asks whether that is enough, what the estimate looks like, and whether
its errors have a direction.

## Instrument (no simulation change)

An estimator over an existing corpus of observable logs:

- a body that **enters** the hidden region crosses an edge and was last seen just
  **outside** it (within one step, `speed·dt`);
- a body that **exits** was first seen again just **outside** the far edge.

So from `enter_occ` / `exit_occ` events with their `side` and `pos`:

| observation | implies | estimate |
|---|---|---|
| `enter_occ` side `left` | `pos.x ≤ x0 < pos.x + step` | `x0_hat = min(pos.x + step)` |
| `exit_occ` side `right` | `pos.x − step < x1 ≤ pos.x` | `x1_hat = max(pos.x − step)` |
| `enter_occ` side `bottom` | `pos.y ≤ y0 < pos.y + step` | `y0_hat = min(pos.y + step)` |
| `exit_occ` side `top` | `pos.y − step < y1 ≤ pos.y` | `y1_hat = max(pos.y − step)` |

Each estimate is therefore an **upper** bound on the true edge on the near side
and the tightest such bound in the corpus: the estimated region is **contained in**
the true one. That asymmetry is a prediction, not a nuisance.

## World and corpora

True world: `o = (40,60,35,65)`, `o2 = (46,54,35,65)` → blind `(46,54,35,65)`,
`dt = 0.1`, `speed = 3` (step `0.3`).

- **full corpus** — horizontal bodies on lanes `y ∈ {36,40,44,48,52,56,60,64}`
  from both sides, plus vertical bodies at `x ∈ {47,50,53}` from top and bottom.
  All four edges are crossed.
- **horizontal-only corpus** — the same horizontal bodies, no vertical ones. Left
  and right edges are crossed; **top and bottom are never crossed**, so `y0, y1`
  should be reported as **unknown**, not guessed.

Task points for the consequence test (`t* = 90`, one body each): the R-P1.21 set
`x ∈ {42,46,48,52}` on lane `y = 45`, i.e. two outside and two inside the blind
region.

## Predictions (fixed now)

- **P1 (the self-model is identifiable to one step).** From the full corpus the
  estimate is correct within one step on all four edges: `0 ≤ x0_hat − x0 ≤ step`,
  `0 ≤ x1 − x1_hat ≤ step`, and the same for `y`. The estimate is a **subset** of
  the truth, never larger.
- **P2 (and abstains when it cannot see).** The horizontal-only corpus yields a
  `None` (unknown) for both `y` edges, and correct-within-a-step `x` edges. An
  estimator that guessed `y` would be reporting knowledge it does not have.
- **P3 (the errors have a sign).** Using the full-corpus estimate to predict
  identifiability on the task points, **no error is pessimistic**: the estimator
  never calls a truly-identifiable event "blind". It may call a truly-blind event
  "identifiable" (optimistic), and with this estimate it should, for points
  within one step of an edge.
- **P4 (good enough to plan with).** On the task points that are at least **1
  unit** clear of every true edge, prediction from the estimate equals the truth
  for all points, so a plan built on the estimate scores the same as one built on
  the truth.

## Prior

**0.8** for P1/P2/P3 — they follow from the geometry of crossing events and the
one-step resolution, and the estimator is deterministic. **0.65** for P4: it needs
the task points to be clear enough of the edges, and `46` sits exactly on the
blind edge in this harness (the standing boundary case), so the "at least 1 unit
clear" subset may be smaller than I expect.

## Rules

- No retune. A falsified prediction is a receipt.
- Corpora are declared here (lanes, x positions); no lane added afterwards.
- Abstention is a first-class outcome: an estimator that returns `None` for an
  unobserved edge is correct behaviour, not a failure.

## Execution status — run 1, 2026-11-22: all four UPHELD

```
true blind region      : (46.0, 54.0, 35.0, 65.0)   step 0.3
full-corpus estimate   : (46.3, 53.8, 35.2, 64.9)   samples {left 4, right 4, bottom 2, top 2}
horizontal-only        : x0=46.3 x1=53.8 y0=None y1=None   unknown (y0, y1)
```

- **P1 UPHELD** — within **one step** on all four edges and **contained**: the
  estimate under-reports its own blind spot rather than over-reporting it.
- **P2 UPHELD** — the horizontal-only corpus returns `None` for both `y` edges:
  it abstains instead of guessing, and `blind_membership` returns `None` for a
  point covered by an unknown edge.
- **P3 UPHELD** — over the task points the errors are **all optimistic**: exactly
  one, at `(46, 45)`, which sits *on* the true edge. No pessimistic error exists,
  and the subset property explains why it cannot.
- **P4 UPHELD** — on points at least 1.0 clear of every edge, prediction from the
  estimate equals the truth, so a plan built on the estimate scores identically.

### The finding

> An observer can recover its own blind region from its own log — to one step,
> always as a **subset** of the truth, and with **abstention** where it never
> crossed an edge. Its errors are therefore **one-signed**: it can believe it is
> less blind than it is, never more. Self-knowledge is conservative by
> construction, because a boundary is only learned where a body crossed it.

That is the loop closing: R-P1.21 measured what a wrong self-model costs, R-P1.28
that the cost is a cliff at certainty, and this card shows the model is
**learnable** from the same log the law is about — with a known bias direction.

### What this does *not* say

The estimator assumes the blind region is a single axis-aligned rectangle (it
returns one rect), that the step is known, and that the corpus is representative
enough to cross each edge. With `blind_cells`-style multi-rect blind sets it would
need one estimate per cell — not claimed here. Noise is out of scope: the
estimator reads crossing positions that the noise model would corrupt, and the
one-step geometry is the tolerance.
