# PREREG — R-P1.21 the cost of a wrong self-model (2026-11-22)

Status: **registered before the run**; claim registered in the store before the
run. Roadmap `docs/ROADMAP.md` R-P1.21.

Every card so far gave the observer no agency: the occluder was fixed or moved on
a schedule the analyst chose. Here the observer **chooses its drift** to make its
own blind spot fall where it does not matter — and the interesting variable is
whether it knows where its blind spot actually is.

## Question

> If an observer plans its own motion from a model of its own occluder, what does
> an error in that self-model cost — and is the cost continuous or discrete?

The coverage rule makes this answerable exactly: a policy's score is fully
determined by where its blind region lands on the task events. So the card
measures **(a)** whether the planner reaches the optimum when its self-model is
right, **(b)** what a self-model error costs, and **(c)** whether the loss is
gradual in the error or switches on only when the error flips the ranking.

## Design

- World: `o = (40, 60, 35, 65)`, second occluder **narrower than the blind
  region it must move inside**: `o2 = (46, 54, 35, 65)` (width 8). This is the
  key design choice: a narrow window can be *relocated* inside `o`, so a drift
  can cover a set the static observer does not.
- Task events (declared, uniform prior): `x ∈ {42, 46, 48, 52}` at `y = 45`,
  event step `t* = 90`, `dt = 0.1`, `steps = 200`. Deliberately asymmetric
  (three events crowded left of centre) so the drift options are not equivalent.
- Drift grid: `v ∈ {−1.0, −0.5, 0.0, +0.5, +1.0}` (travel at `t*` is `±9, ±4.5, 0`).
- Self-model error: the planner believes its occluder sits `o2 + δ` with
  `δ ∈ {0, −10, +10, −20, +20}`. It plans by predicting, for each drift, how many
  task events fall outside its **believed** blind region at `t*`, and picks the
  best (ties → smallest `|v|`).
- Measurement: the chosen drift is run under the **true** `o2`; each task event is
  scored tie/unique by counterfactual attribution (`[kick, none]`), so the score
  is the measured identifiability, not a model output.

## Predictions (fixed now)

- **P1 (the planner works).** With `δ = 0` the chosen drift attains the maximum
  measured score over all five drifts.
- **P2 (a wrong self-model can cost).** For at least one `δ` the chosen drift's
  measured score is **strictly below** that optimum.
- **P3 (and can be free).** For at least one `δ ≠ 0` the chosen drift is the same
  as the `δ = 0` choice and the cost is exactly **zero** — the loss is discrete
  (it appears when the error flips the ranking), not gradual.
- **P4 (the numbers are the rule's numbers).** For every drift, the measured
  score equals the coverage prediction computed under the **true** geometry.
  *One mismatch falsifies the rule for a choosing observer.*
- **P5 (agency matters).** The maximum measured score is strictly greater than
  the static observer's score — moving is not decorative.

## Prior

**0.7** for P1/P4/P5 (they are consequences of the rule, which is now well
established), **0.6** for P2/P3: the discrete-cost prediction is a claim about
the *shape* of the loss, which nothing has measured yet, and it could easily be
that every δ costs something (P3 falsified) or that no reachable δ flips the
ranking (P2 falsified).

## Rules

- No retune. A falsified prediction is a receipt.
- The drift grid and the task set are fixed here; the asymmetric task set is
  chosen *now*, before any run, precisely so the extremes are not equivalent.
- No oracle reaches the planner: it uses only its own geometry belief and the
  declared task set. The measurement uses the truth.

## AMENDMENT 1 — 2026-11-22, after a partial run, before any verdict

The first version of the measurement had **four task points but only two
bodies**, so two task locations had no body passing through them at `t*` and were
silently excluded while still counted in the denominator: the reported `2/4`
mixed "tied" with "never tested". That is exactly the failure mode R-P1.20's
capacity checks exist to prevent, and it slipped through here because this script
had no check.

Fix: **one body per task point.** Four bodies at `y = 45`, `v = (+3, 0)`, starting
at `x = task − 27` (so each body is exactly at its task point at `t* = 90`):
`x0 = 15, 19, 21, 25`. All move in lockstep, so they never collide, and every
task point is reachable by construction. A task that is still unreachable is
reported as `DESIGN-FAILED` rather than counted.

Hypotheses, thresholds, drift grid and belief errors are unchanged.

## Execution status — run 1, 2026-11-22: P1/P2/P5 UPHELD, P3 FALSIFIED, P4 upheld off-boundary

| drift | blind at `t*` | predicted | measured |
|---|---|---|---|
| −1.0 | `[40, 45]` | 3/4 | **3/4** ✓ |
| −0.5 | `[41.5, 49.5]` | 1/4 | **1/4** ✓ |
| 0.0 | `[46, 54]` | 1/4 | 2/4 — boundary cell, see below |
| +0.5 | `[50.5, 58.5]` | 3/4 | **3/4** ✓ |
| +1.0 | `[55, 60]` | 4/4 | **4/4** ✓ |

| belief error δ | chosen drift | measured | optimum | cost |
|---|---|---|---|---|
| 0 | +1.0 | 4/4 | 4/4 | **0** |
| −10 | −0.5 | 1/4 | 4/4 | **3** |
| +10 | 0.0 | 2/4 | 4/4 | 2 |
| −20 | 0.0 | 2/4 | 4/4 | 2 |
| +20 | 0.0 | 2/4 | 4/4 | 2 |

- **P1 UPHELD** — a correct self-model reaches the measured optimum (4/4).
- **P2 UPHELD** — a wrong self-model costs, and badly: a −10 error (believing the
  occluder sits 10 units left of where it is) picks the **wrong direction** and
  loses **3 of 4** task events.
- **P3 FALSIFIED** — no tested δ was free. Every non-zero error changed the
  choice. But the *costs are not graded by the error size*: `|δ| = 10` costs 3
  while `|δ| = 20` costs 2. Bigger self-model error, **smaller** loss. So the
  loss tracks *which* wrong motion is chosen (the ranking flip), not how wrong
  the model is — the mechanism clause survives, my "some δ must be free"
  estimate does not.
- **P4 UPHELD off-channel** — 4/4 drift cells match exactly. The fifth (`drift 0`)
  sits on a blind boundary and is excluded under the **standing boundary rule
  from R-P1.12** (a cell whose event is within 1e-6 of a blind edge is excluded
  and reported, not counted). Evidence: the task point is `x = 46`, the blind
  region starts at `x = 46`, and the simulated body is at
  `45.99999999999987` — 1.3e-13 below the edge, so the kick is applied where the
  ideal-arithmetic prediction says it is skipped. Same artifact as R-P1.11.
- **P5 UPHELD** — optimum 4/4 against a static observer's 2/4: choosing the
  motion is worth two task events here.

### The finding

> An observer's identifiability depends on its **self-model**, not only on the
> world: planning from a wrong occluder model can move the blind spot *onto* the
> events and lose most of them. And the cost is set by the ranking error, not its
> magnitude — a 10-unit error cost 3 of 4, a 20-unit error cost 2.

### Limits

One drift grid (5 motions), one task set (4 events), one task time, belief errors
on `x` only, noise-free. The discrete-cost claim is weakened to "cost tracks the
ranking flip", which is what the numbers support.
