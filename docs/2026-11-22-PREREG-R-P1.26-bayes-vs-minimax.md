# PREREG — R-P1.26 Bayesian vs minimax planning under self-model error (2026-11-22)

Status: **registered before the run**; claim registered in the store before the
run. Roadmap `docs/ROADMAP.md` R-P1.26.

R-P1.24 showed a minimax hedge over a ±20 unit belief set scores **3/4** where the
worst naive plan scores **1/4**. Its prior was flat, so the natural challenge is
the decision-theoretic one:

> Is the hedge paying because robustness is the right answer here, or because a
> flat prior happened to agree with it? And what happens when the prior is
> confident — and wrong?

## Design

The R-P1.21/R-P1.24 harness, unchanged: `o = (40,60,35,65)`,
`o2 = (46,54,35,65)`, tasks `x ∈ {42,46,48,52}` on lane `y = 45`, `t* = 90`, one
body per task, drifts `v ∈ {−1, −0.5, 0, +0.5, +1}`.

Three planners, each choosing a drift to maximise an **expected** predicted
score over the belief set `Δ = {−20, −10, 0, +10, +20}`:

- **bayes-flat** — uniform prior over `Δ`;
- **bayes-peaked** — mass 0.8 on the planner's own belief being correct, rest
  uniform (an honest, confident observer);
- **bayes-wrong** — mass 0.8 on `δ = −20` while the truth is `δ = 0` (a confident
  observer whose confidence is misplaced).

Baselines from R-P1.24: **minimax** (worst-case over `Δ` → drift `−1.0`, measured
3/4) and **oracle** (4/4).

−0.5 → 1/4, 0.0 → 2/4, +0.5 → 3/4, +1.0 → **4/4**.

## Predictions (fixed now)

- **P1 (a flat prior lands on the hedge).** bayes-flat picks `−1.0` and measures
  **3/4**, identical to minimax — with no preference information, expected-utility
  and worst-case agree.
- **P2 (an honest, confident prior skips the hedge at no cost).** bayes-peaked
  picks `+1.0` and measures **4/4**: when the belief is right and the observer
  knows it, hedging is an expense with no return.
- **P3 (a misplaced confident prior is worse than the hedge).** bayes-wrong
  picks `0.0` and measures **2/4**, strictly below minimax's 3/4. Minimax is
  robust to prior misspecification; Bayes inherits whatever the prior says.
- **P4 (the law underlies all three).** For each chosen drift, identifiability
  predicted from the **true** geometry equals the measured count.

## Prior

**0.7** for P1/P2/P4. **0.55** for P3: it needs the misplaced prior to land on a
genuinely worse drift, and the plan table shows `0.0` scoring 2/4 against
minimax's 3/4, so the numbers say it should — but "should" on paper is what the
last three cards kept falsifying.

## Rules

- No retune. A falsified prediction is a receipt.
- One prior per planner and one belief set, both declared here.

## Execution status — run 1, 2026-11-22: P1/P2/P4 UPHELD, P3 FALSIFIED

| planner | drift | measured | regret |
|---|---|---|---|
| bayes-flat | −1.0 | **3/4** | 1 |
| bayes-peaked (honest) | +1.0 | **4/4** | 0 |
| bayes-wrong (p(−20)=0.8) | −1.0 | **3/4** | 1 |
| minimax | −1.0 | 3/4 | 1 |
| oracle | +1.0 | 4/4 | 0 |

- **P1 UPHELD** — a flat prior lands exactly on the hedge.
- **P2 UPHELD** — an honest, confident prior skips the hedge with **zero** regret.
- **P3 FALSIFIED.** I predicted the misplaced prior would pick `0.0` (2/4) by the
  smallest-`|v|` tie-break and lose to minimax. It picked `−1.0` and scored 3/4,
  matching minimax. Cause, and it is my error not the planner's: the prereg's
  plan table printed expected scores to **two decimals**, where the `δ = −20`
  row's five options all showed `3.2`. They are *not* equal — they differ at the
  third decimal — so the tie-break never fired and the prior's tiny residual
  weight decided it. The prediction rested on rounded numbers.
- **P4 UPHELD** — the law underlies all three plans.

### What this narrows, honestly

The claim that "Bayes inherits prior error while minimax is robust" is **not
refuted and not demonstrated** by this card. In *this* world a confident wrong
prior is harmless, because the row it leans on (`δ = −20`: every drift predicted
4/4) still contains the drift the hedge would pick — the wrongness cancels.

I can see, from the same plan table, which priors *would* be harmful (a peak on
`δ = +10` prefers `0.0`, measured 2/4). Choosing that prior **after** seeing this
result would be retuning, so it is not evidence. The honest version is a declared
sweep of *all five* peaked priors — R-P1.27 — not one selected peak.
