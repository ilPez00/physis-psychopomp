# Plan — R-P1.8 counterfactual attribution (2026-11-21, before execution)

Status: **PLAN**, written before the run. Roadmap `docs/ROADMAP.md` R-P1.8.
Mission P1 §5: OBSERVED / INFERRED / COUNTERFACTUAL / REFUTED must be
distinguishable. This card asks the consequential question: **given an
observed episode and a finite set of declared intervention hypotheses, which
one explains the observation?**

## Predictions (fixed now)

- **P1** — with deterministic re-simulation, the true hypothesis has motion
  distance exactly 0 and is the unique top-1 when candidates are distinct.
- **P2** — a hypothesis that the simulator skips (kick on a hidden ball) is
  **observationally identical to "no kick"**; attribution must report a tie
  (ambiguity set), never silently pick one. This is an identifiability limit,
  stated, not a bug.
- **P3** — a permuted-score control scores at chance (1/K): the metric is not
  trivially solvable, and accuracy must beat that control.
- **P4** — for a unique winner the margin (second-best minus best) is > 0 and
  every decoy is strictly farther.

If the truth is not at distance 0, the instrument is wrong (audio: later
noise/degradation would break exactness — not in this card, which is
noise-free by construction).

## Instrument

`psychopomp/attribution.py`:
- `Hypothesis = Intervention | None` (none = "no intervention");
- `signature(ep)` — enter/exit events as `(kind, t, side, v)`;
- `motion_distance(obs, cand)` — sum of velocity distances plus penalties for
  side/count mismatches and a light time displacement;
- `candidate_episode(...)` — re-simulated with `counterfactual:v0.1`
  provenance (never history);
- `attribute(observed, hypotheses, ...)` — ranked scores + ambiguity set.

Candidates are **declared**, finite and typed; the task is ranking, not open
hypothesis generation. All candidates are counterfactuals; only the observed
run is an execution.

Predictions: **P1 upheld** (truth at distance 0, unique, both classes);
**P2 upheld** (a kick on a hidden ball ties with "no kick" — test-pinned as
the only real ambiguity); **P3 upheld** (permuted-score control 0/12, chance
0.111); **P4 upheld** (positive margins, every decoy strictly farther).

Four findings from getting the instrument honest (each caught by a failing
test, not by argument):

1. **Simultaneous events need canonical ordering.** Identity-free events at
   the same step have no observable order; a positional sort fabricated a
   distinction between symmetric hypotheses.
2. **The signature needs positions.** Velocities alone made a kick at t=10
   and t=30 indistinguishable (same exit velocities, same event times).
3. **Identity-free ≠ permutation-symmetric.** Two identical bodies on
   different lanes are distinguishable because their paths differ in space;
   the "wrong ball" tie I first expected was a signature artifact.
4. **The only irreducible ambiguity is a skipped intervention** (ball hidden
   when kicked); that is a physics limit of the setup, reported as a set.
