# Preregistration — R-P1.78: the partition structure is why one query resolves

Claim `77bf0998-3d3c-4705-8276-a02c8cd2b438`, registered at **prior 0.5** before the run. Freeze on origin before
any measurement. Status at freeze: **not measured**.

R-P1.77 falsified the world-count explanation for this lane's biggest
inconsistency and named the right one: *"the difference is the partition
structure, not the count."* It also measured the evidence for that on one seed —
the most balanced candidate edge splits the surviving set **1 vs 11**.

This card makes that measurement the object, and asks whether a fixture can be
**built** so a query partitions the posterior, which is what R-P1.47's scalar table
does by construction.

## The two structures, stated exactly

- **R-P1.47**: `Y = S + M·a` over law `M ∈ {−1,+1}` and state `S ∈ {−3,−1,1,3}`.
  Eight joint rows. Reading `sign(Y)` at `a = 4` divides them **4 vs 4**, and the
  divisor is exactly the law bit. One query, complete resolution.
- **the graph fixture**: a candidate edge's membership across cap-consistent
  completions is **skewed**. Measured (R-P1.77, 6 seeds): the most balanced
  available split is **1 vs 11** at one missing edge, so no query in the pool is
  near a divisor.

Why it is skewed: with `MISSING = 1` every surviving world is `observed ∪ {e}` for
some candidate `e`, so a world contains `e` only when `e` **is** the missing edge —
every edge is in exactly one world out of 12, not six. The structure is forced by
the generator, not a property of graphs.

## Design

Three fixtures, one query each, 120 held-out cases:

- **A — the repair generator** at `MISSING = 1`: the R-P1.77 measurement, as the
  anchor. Predicted: active ≈ passive.
- **B — a balanced-completion generator**: same entities, but a world is
  `observed ∪ C` for a **subset `C` of size `MISSING` chosen so each candidate
  appears in about half the worlds. Constructed by sampling subsets and **rejecting**
  those whose per-edge frequencies fall outside `N/2 ± 0.25N`, so "balanced" is
  enforced by construction and then **measured**, not assumed.
- **C — the same as B with `MISSING = 2`**, so the balancing is not an artefact of
  one size.

The only difference between A and B is the frequency structure; entities, seeds,
sensor, decoder and the query rule are identical.

## Frozen predictions

- **P1 — the anchor reproduces.** Fixture A gives active − passive ≤ 0.05, as
  R-P1.77 measured (+0.022 at `n = 3`).
- **P2 — the balancing is real.** In fixture B, the **measured** per-edge frequency
  spread is within `N/2 ± 0.25N` for every candidate edge, and the most balanced
  split is at worst **40/60**. If construction fails to balance, the cell is
  reported **not constructible** rather than run unbalanced.
- **P3 — a structural split converts into resolution.** In fixture B, active beats
  passive by **≥ 0.10**, and the surviving set after one query is at most **0.6N**.
  This is the claim R-P1.77 could not reach.
- **P4 — it is not the size.** Fixture B's world count is **within a factor of 2**
  of fixture A's, so a resolution difference cannot be attributed to fewer worlds.
  If B has far fewer worlds, the cell is reported as confounded and the card says
  so.
- **P5 — the shuffled control stays at passive** in every fixture, so the effect is
  information and not a second query.

Any prediction may fail and is kept. **P3 is load-bearing**: if a fixture built to be
balanced still shows no resolution, then partition structure is not the explanation
either, and R-P1.47's contrast remains open with two candidate answers eliminated.

## What this card may and may not conclude

- It **may** say that a balanced partition structure is sufficient for one query to
  resolve, and that the graph generator's skew is why the repair cards get nothing.
- It **may not** claim a graph fixture an operator would meet — B is **constructed**
  to be balanced and no real graph is. The claim is about mechanism, not prevalence.
- It **may not** open E6: the analytic rule is what resolves in B, and no learned
  ranker is involved.
- It **may not** retune R-P1.47 or any repair card.

## Controls and honesty

- Fixture A is the anchor and must reproduce a measured number from a different card.
- Balanced-ness is **enforced and then measured**; the receipt prints the observed
  per-edge frequency histogram, so B cannot quietly run unbalanced.
- P4 exists to keep the size explanation dead: if B is much smaller than A, a win
  there proves nothing and the card reports the confound instead of the win.
- Verdict vocabulary: `PASS` / `FAIL` / `UNVERIFIABLE`.

## Limits

Two `MISSING` values, `n ≤ 4`, one predicate, one query. A balanced fixture with more
candidates is a scaling question R-P1.67 showed is expensive, and is not attempted.
