# Preregistration — R-P1.51: decoder contract on a controlled corrupted graph
(2026-11-23)

Claim `c9e2e6c8-d1aa-4489-ab51-2c2e9a98cb3d`. Prior: **0.85**. Freeze this file
on origin before running. Status at freeze: **not measured**.

Scope, stated first because it limits every number below: this measures the
**decoder given a set of admissible worlds**, not a predictor that produces those
worlds. Nothing here is a claim about repair precision of a learned system, and
no number here licenses "the graph was repaired".

## Fixed graph (no randomness)

Entities `n1…n6`, one predicate `X`, plus one `Y` edge:

```
T = { (n1,X,n2), (n2,X,n3), (n3,X,n4), (n4,X,n5), (n5,X,n6), (n1,Y,n6) }   # 6 true edges
snapshot = T − { (n2,X,n3), (n5,X,n6) }                                   # 4 observed, 2 missing
```

| arm | admissible worlds | construction |
|---|---|---|
| **exact** | `{T}` | the truth |
| **noisy** | `{snapshot ∪ (n2,X,n4)}` | one fabricated edge, no true additions |
| **shuffled** | `T` with targets permuted `n1→n4, n2→n5, n3→n6, n4→n1, n5→n2, n6→n3` | same edge count, same entities, no true edge survives |
| **empty** | `{}` | nothing survived |

All arms share the snapshot, its revision and its evidence seqs, so a difference
between arms is the worlds and nothing else.

Precision = proposed edges that are in `T` ÷ proposals. Recall = true missing
edges proposed ÷ 2.

## Predictions (fixed now)

- **D1 — exact.** Proposals are exactly the two missing true edges: recall
  **1.0**, precision **1.0**, and every proposal carries
  `status = HYPOTHESIZED`.
- **D2 — shuffled.** Precision **≤ 0.5** and `false ≥ true`: a world with the
  right size and the wrong content must not read as a repair. Expected 0.0.
- **D3 — empty.** Exactly one `unknown` operation, **0** proposals, and no
  `request_evidence`.
- **D4 — disputed.** With `worlds = {T, noisy}` the decoder emits both sides
  (`(n5,X,n6)` and `(n2,X,n4)`) marked `disputed`, keeps the agreed
  `(n2,X,n3)` marked `all_surviving_worlds`, and emits **exactly one**
  `REQUEST_EVIDENCE` naming the positive-gain probe.
- **D5 — no application.** In every arm the plan's `verifier.status` is
  `NOT_EVALUATED`, `base_revision` equals the snapshot's revision, and no
  operation carries a status other than `HYPOTHESIZED` or `unknown`.

## Rules

Any arm whose construction does not match the table (capacity failure) is
reported as a failure and not scored. No arm is dropped or re-tuned. Two
order-shuffled decodes per arm must serialise identically.

## Limits

- One hand-built graph, one corruption depth. No scale, no noise model.
- The decoder cannot retract (E4 is restricted until `as-of` and
  `removed:rel|…` are measured), so a false edge **already in the snapshot** is
  out of scope here.
- Passing this card shows the proposals obey the contract. It does **not** show
  that the proposals are useful, still less that Physis would admit them.
