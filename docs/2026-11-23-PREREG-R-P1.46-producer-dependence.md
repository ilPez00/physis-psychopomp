# Preregistration — R-P1.46 producer dependence (2026-11-23)

Claim `e1811bf2-f261-4a86-bc7e-ada56a6f1f86`, registered before implementation
and run. Prior: 0.85. This is a constructed, exact integration check of
observable-log distinguishability, not an estimate of field reliability.

## Design

Use two stationary bodies at `(20,50)` and `(75,50)` and their relabelled twin.
One rectangular blocker `(10,30,40,60)`, no second blocker, one simulation step,
marker period 2, perfect marker content when visible, no noise or interventions.
The hidden body contributes no marker. Take the sole observable marker at `t=0`
and offer it to two simulated transport producers. Delivery masks `(0,0)`,
`(1,0)`, `(0,1)`, `(1,1)` indicate which producers deliver it. Use the **same**
mask in both worlds. Producer provenance names a transport, not a body. Compare
canonical sequences of observable events including source and payload; unequal
sequences mean the two declared worlds are distinguishable, not that a general
decoder has been evaluated.

## Frozen predictions and controls

- **M1 (capacity):** exactly one marker in each world, same step and position,
  different tags. No oracle records. Each producer delivers in exactly half
  the probability mass in every two-producer arm.
- **M2 (dependence):** shared masks `00/11` each weight 1/2 resolve **1/2**;
  all four independent masks each weight 1/4 resolve **3/4**; complementary
  masks `10/01` each weight 1/2 resolve **1**. Single producer A on the same
  masks resolves **1/2** in all three arms. Exact fractions, zero tolerance.
- **M3 (payload control):** for every mask, replacing tags with one anonymous
  value in both worlds preserves delivery counts/source/position and resolves
  **0/4** masks. No delivery also yields a tie with real tags.

If capacity fails, record the failure and do not score M2/M3. No tuning,
additional cells, stochastic draws, or production API. With these restrictions
the two-producer answer is `1 − P(both fail)`, not a function of the marginals
alone. Neither different view geometries nor wrong/spurious tags are tested.
