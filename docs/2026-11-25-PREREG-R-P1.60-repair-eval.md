## Why R-P1.56 cannot answer the E5 gate

Two defects, both in the scoring, not in the fixture:

1. **Recall denominator.** `summarise()` divided correct recoveries by
   `cases * 6`, the size of the *whole* truth set. Only 3 of 6 edges were
   hidden, so every recall figure is half its true value. Held-out C recall was
   reported `0.097`; against the 36 genuinely missing edges it is `0.194`.
2. **The null was sized wrong.** Arm D drew a 6-edge pseudo-truth from a
   candidate pool of 20–24 edges while the arm proposes 3 edges. Its expected
   precision is therefore `≈ 6/|pool| ≈ 0.28`, not the chance value for the
   actual decision, which is `3/|pool| ≈ 0.14`. Measured C `0.194` was read as
   *below chance* against `0.282`; under the correct null it is *above* chance.
   The card's H4 threshold (`≤ 0.25`) encoded the same mistake.

Consequence: R-P1.56's `NO HEADROOM` verdict is not supported by its own
numbers. It is recorded as **exploratory**, its receipt is left byte-identical,
and E5 is re-measured here under a null that matches the decision.

## Question

On worlds whose observations cannot decide the graph, does the
surviving-world candidate set carry recoverable repair signal, does a
deterministic support rule reach it, and how much precision remains for a
learner?

## Fixture (unchanged, and held out from labels)

Same generator, same seeds `0..23`, same split drawn before any feature is
extracted: **12 development (seeds 0–11), 12 held-out (12–23)**. Each world is
`n = 8` entities (`node`, `port`), true edge set of `m = 6` `LINK`s from
kind-admissible pairs (`node→node`, `node→port`), closure rule no in/out degree
above 2. Observation reveals every entity id and `k = 3` of the 6 true edges,
nothing false. Candidate worlds are the 6-edge sets containing the observed
edges and satisfying closure. `psychopomp.graph_patch.decode` produces the
candidate pool from those worlds, unchanged.

The decoder receives partial observations only. Truth edge sets are read by the
scorer and by nothing else; they are not features, not candidate filters, and
not in observed history.

## Arms (same cases, same candidates, same budget)

- **A — no repair:** propose nothing.
- **B — consensus:** propose only edges present in every surviving world.
- **C — support rank:** top 3 edges by surviving-world support, ties by
  `(source, predicate, target)` ascending. The arm a learner must beat.
- **D — null (corrected):** C's ranking scored against a pseudo-truth of
  exactly `|missing| = 3` edges drawn uniformly from `pool \ observed`,
  200 draws per case, seed `seed*7919+1`. This is the exchangeable null for a
  3-edge decision over the same candidate pool.
- **E — closure-forced 0.9:** edges in at least 90% of surviving worlds,
  tie-broken as in C. A precision-first deterministic rule that is not vacuous
  by construction; B is included unchanged so its emptiness is re-measured, not
  assumed.

No arm gets a different candidate set, closure rule or observation budget.

## Metrics (every figure prints its denominator)

Per arm and per split:

- **correct recoveries** — proposed edges that are missing true edges;
- **false corrections** — proposed edges that are not in the truth;
- **precision** — recoveries / proposed;
- **recall** — recoveries / **missing true edges** (3 per case, 36 held-out);
- **abstentions** — cases with zero proposals;
- **completion error** — mean over the case's candidate pool of
  `(1[e ∈ truth] − 1[e ∈ proposal])²`, averaged over cases. This charges A for
  every missing edge it silently denies, which precision and recall cannot see.

## Frozen checks

- **H1 — the fixture is ambiguous.** Every case has ≥ 2 surviving worlds and 0
  cases are determined. If it fails the run is **VACUOUS**, not a win for any
  arm.
- **H2 — the null is calibrated.** Held-out D precision is within **±0.05** of
  the analytic `3/|pool|` mean over the same cases. If it is not, the run is
  **INVALID**: a miscalibrated null measures nothing, and the null is fixed in
  a new card rather than retuned here.
- **H3 — support ranking beats the null.** Held-out `C_precision − D_precision
  ≥ 0.10` **and** C beats its own case's D median in **≥ 2/3** of held-out
  cases (paired per case, not only pooled).
- **H4 — proposing beats silent denial.** Held-out C completion error is
  strictly below A's.
- **H5 — headroom follows mechanically.** HEADROOM only if H3 and H4 hold
  **and** `1 − C_precision ≥ 0.10`. Otherwise **NO HEADROOM** and E6 stays
  closed.

## Stop rules

- No threshold is retuned after measurement. A failed check is recorded as
  failed; a defective check is corrected only in a new frozen card.
- H2 failure stops the card at INVALID with no verdict on the arms.
- If H5 returns HEADROOM, E6 may trial an offline ranker on these same
  held-out cases and budgets. It is promoted only if held-out precision is at
  least `C_precision + 0.10` at recall `≥ C_recall` **without increasing false
  corrections**, and it emits order, confidence and abstention only — never an
  assertion, approval or tool call.
- A learner that cannot beat C on the corrected null is not run again on this
  fixture.

## Limits

- Synthetic graphs, one predicate, one closure rule, one observation budget
  (3 of 6). The candidate pool is the decoder's claimed set, so an edge no
  surviving world contains is never proposed — a real restriction of this
  measurement.
- Precision and recall over candidate edges say nothing about whether a repair
  is safe to write. The writer's evidence and approval boundary is a separate
  gate and a learner never holds it.
- This card supersedes R-P1.56's **interpretation** only. Its numbers, its
  `FAIL`/`NO HEADROOM` record and its receipt remain as evidence of the defect.
