# PREREG — R-P1.11 per-event coverage rule (2026-11-22)

Status: **registered before the run**. Roadmap `docs/ROADMAP.md` R-P1.11.
R-P1.10 falsified the over-general claim and left a *derived* rule. Because that
rule was read off R-P1.10's own failures, R-P1.10's data cannot test it. This
file fixes a fresh grid and an **analytic** prediction — no measurement is
consulted to build the predictions.

## The rule under test

> An intervention is identifiable from the observable log **iff** its event
> location is not inside the blind region `o ∩ o2`. Aggregate blind area is a
> proxy for that and carries no independent information.

Prediction for one cell, stated analytically: the kick at step `t` is applied
only if the body is observable at step `t`, i.e. iff its position
`(x0 + v·dt·t, y)` is outside `o ∩ o2`. If it is inside, the simulator skips it,
the counterfactual equals the no-kick world, and the truth ties with the null
(`d(true) = d(null) = 0`).

## Fresh grid (nothing reused from R-P1.10)

Seeds: `x0 ∈ {20, 24, 28, 32, 34}`, ball 1 at `x0 + 4`, both lanes `v = (3, 0)`,
`y = 45` and `y = 51`, `steps = 200`, kick at `t = 60`, `dv = (0, 1.5)`.

Event locations at `t = 60`: ball 0 `x = x0 + 18 ∈ {38, 42, 46, 50, 52}`;
ball 1 `x = x0 + 22 ∈ {42, 46, 50, 54, 56}`. No wall bounce occurs before `t=60`
(`max x = 56 < 99`).

Observer sets (fresh rects, not R-P1.10's):

| label | `o2` | blind region `o ∩ o2` | which lane is blind |
|---|---|---|---|
| `ov-a` | `(48, 68, 35, 65)` | `x ∈ [48,60], y ∈ [35,65]` | both |
| `ov-b` | `(44, 64, 35, 65)` | `x ∈ [44,60], y ∈ [35,65]` | both, wider |
| `ov-c` | `(42, 62, 46, 70)` | `x ∈ [42,60], y ∈ [46,65]` | lane `y=51` only |

Two episodes per cell (true kick on ball 0, then on ball 1): 5 seeds × 3 sets ×
2 lanes = **30 cells**.

## Predictions, derived by hand from the rule (before the run)

| observer set | lane `y=45` | lane `y=51` |
|---|---|---|
| `ov-a` | hidden for `x ∈ {50, 52}` → **2/5 unique** | hidden for `x ∈ {50, 54, 56}` → **3/5 unique** |
| `ov-b` | hidden for `x ∈ {46, 50, 52}` → **2/5 unique** | never hidden → **5/5 unique** |
| `ov-c` | never hidden (`y=45 ∉ [46,65]`) → **5/5 unique** | hidden for all `x ∈ {42,…,56}` → **0/5 unique** |

Every one of the 30 cells also has a per-cell prediction: tie iff the event
location is inside the blind region. Both the per-cell pattern and the six rates
above are checked.

## Thresholds

- **H1 (the rule).** All **30/30** cells match the analytic per-cell prediction.
  *Falsified by a single mismatch* — that is the point of a rule: it is exact.
- **H2 (blind area carries no extra information).** `ov-c` lane `y=45` is 5/5
  unique with blind area 540 while `ov-c` lane `y=51` is 0/5 with the *same*
  540. Same area, opposite outcome: area alone cannot predict.
  *Falsified if* the two lanes of `ov-c` differ from 5/5 and 0/5.
- **H3 (control).** Permuted-score control within `1/3 ± 0.15` in every cell
  (200 draws, uniform among tied minima).
- **H4 (no ceiling).** No cell may be unique-correct for a reason the rule does
  not name: the count of unique-correct cells must equal the analytic count
  exactly (14/30 by the table above: 2+3+2+5+5+0).

## Prior

**0.55.** The rule is post-hoc from R-P1.10 and this is its first out-of-sample
test; a fresh grid can falsify it with one cell, so the prior stays near even.

## Rules

- No retune. A single mismatch is a receipt: the rule is then wrong or
  incomplete, and the next card says which.
- Both lanes are part of the test precisely because R-P1.10 only ever kicked
  ball 0.
- No learned arm; deterministic arms settle this.

### The one miss, diagnosed

Cell `ov-c, x0=20, lane y=51`. Predicted: event at `x = 20 + 4 + 18 = 42`,
blind region starts at `x = 42` → inside → skipped → tie. Measured: **unique**,
`d(null) = 20.65`, i.e. the kick was applied.

Cause, measured directly from the trajectory:

```
sim x at step 60 : 41.99999999999992
analytic x       : 42.0
```

The simulator accumulates `v·dt` sixty times (`0.30000000000000004`), landing
1.4e-14 *below* the boundary; the analytic prediction used exact `42.0`, on the
other side of the `x0 <= x` predicate. The rule was not falsified — the
prediction arithmetic was, at a cell deliberately placed on a boundary.

Recorded as falsified anyway, because the threshold was 30/30 and the measured
value is what it is. The corrected card (R-P1.12) excludes boundary cells by a
rule declared *before* its run, and states the boundary caveat as part of the
rule. The grid below is what R-P1.11 used; the script has since been repointed
at R-P1.12's grid, so re-running this grid means restoring these constants:

```
seeds x0 = {20, 24, 28, 32, 34}; ball 1 at x0+4; lanes y = 45, 51
o2: ov-a (48,68,35,65)  ov-b (44,64,35,65)  ov-c (42,62,46,70)
```

### What it still establishes

29/30 exact, with the single failure fully explained by a 1e-14 float artifact,
is strong support for the rule and *no* support for the aggregate-area reading:
`ov-c` lane `y=45` scored 5/5 unique while lane `y=51` scored 1/5 with the same
blind area.
