# R-P1.7 ingest measurement — the consumer side does not exist (2026-11-22)

The roadmap line said "live Physis ingest compatibility **NOT MEASURED**". It is
measured now, from the installed engine (`physis` 1.8.7 on PATH) and its command
surface. Verdict first: **no generic observation ingress exists**, so
`psychopomp.observation/1` cannot be ingested into a Physis world today. The
producer side stands; the gate is not met.

## What was measured

```
physis ingest-sources        -> 12 declared connectors, one per line
physis ingest <SOURCE> [PATH] --url --from-cache --dry-run ...
```


Facts that follow from the surface, not from inference:

- `<SOURCE>` must be a **declared** `<provider>/<layer>`; there is no
  `--schema`, no file argument, no `import`/`record` subcommand anywhere in the
  command list (the closest neighbours are `observe` — scan a *tree* into the
  log — and `ingest` — fetch a *network feed* from the registry).
- Each source carries a fixed emit shape (`geo`, `plain`), a minimum re-fetch
  cadence and a byte ceiling, i.e. a per-source parser, not a generic JSONL
  reader.
- `--url` overrides the feed URL for mirror selection; it does not change the
  parser, so pointing it at a psychopomp export would fail at parse time, not
  ingest it.

## Consequence

The R-P1.7 gate ("round-trip query on a fixture in a Physis world") is **not
met** and cannot be met from the psychopomp side. The missing capability is a
physis-next change: either a declared connector whose emit shape accepts an
external observation stream, or an `import`-style subcommand that validates a
versioned schema (`psychopomp.observation/1`) and appends rows with provenance.

Until then the honest status is: **producer complete, lossless, identity-free,
counterfactual-refusing; consumer absent; compatibility unclaimable.**

Not measured: whether physis-next has an internal observation row schema that
*already* matches `psychopomp.observation/1` closely enough to make a connector
a thin adapter. That requires reading the crate's log writer, not the CLI
surface, and is the first step of any connector work.

roadmap row now says so with this measurement instead of "NOT MEASURED".
